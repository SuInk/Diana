# 记忆检索

跨平台记忆：在机器人配置中启用「跨平台记忆」，默认关闭。参与共享的不同平台机器人都必须启用长期记忆和此开关，并保留平台上下文隔离。仅在群聊回复中按话题相关性检索对方已落库的非敏感群公共事实和摘要，不共享个人偏好、私聊、群规则或会话便签，不拼接其他平台的原始聊天，也不按相同数字 ID 或昵称合并用户。个人结构化记忆按机器人命名空间隔离；旧记忆仅在来源命名空间内读取和更新。此开关与「跨群记忆」独立，保存配置后生效。

公共记忆召回：启用跨群或跨平台共享后，非敏感群公共事实、摘要不要求共同群成员。除原有候选外，单独检索最多 40 条共享公共候选，避免被本群记录挤出检索窗口；之后统一去重、按相关性排序，并遵守原有上下文预算，不是直接注入 40 条。提示词标明「其他群公共记忆」或「其他平台群公共记忆」，不会把它们标成本会话经历。共享池排除个人内容、私聊、群规则和会话便签；原始跨群聊天仍保留共同成员校验，敏感内容不放宽。

跨群历史长期检索：原始聊天不再受 72 小时限制，可检索当前消息时间之前仍保存的全部历史，按相关性优先、近期小幅加权，最终最多补入 4 条文本。本群消息在数据库截取候选前排除，避免挤占其他群的名额。开启「语义检索」并配置 embedding 分组模型后，文字与向量两路各召回最多 40 条候选并融合；跨群向量结果要求余弦相似度至少 0.65，语义命中不再要求字面重合，但仍校验平台和共同成员。向量调用失败会回退文字检索；语义路线只覆盖已建立索引的历史，不会自动批量向量化全部旧消息。开启调试模式后，事件调试记录显示检索范围、两路候选数、过滤原因和补入历史的消息标识；补入历史不代表必然被最终提示词预算保留。

无 embedding 的关联召回：从直接相关的非敏感群公共事实、摘要中选取最多 3 个实体（缺少实体时使用主题），按已有标签精确匹配，补查一跳、最多 24 条关联候选。关联权重衰减后与直接结果统一排序和去重，仍受原有记忆预算及跨群、跨平台开关约束；不会递归扩大范围、共享个人或敏感内容，也不会新增 embedding 调用。尚无实体、主题标签的历史不会被自动猜测关联。

按需查阅：启用 Agent 和长期记忆、且存储可用时，模型可调用 `diana.memory`。`search` 返回短索引和记忆 ID（默认 8 条，最多 12 条），可换关键词继续检索；`read` 读取单条当前有效记忆的全文、提取证据和版本。按 ID 读取同样检查作用域、有效状态及过期时间，不允许绕过权限读取旧版本；证据只是提取时保留的片段，不等于原始聊天全文。Agent 模式下，较长的公共记忆先以约 180 字及 ID 注入，细节由工具按需读取；非 Agent 模式保持原有完整内容和预算裁剪方式。
