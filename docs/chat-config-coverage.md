# 聊天配置覆盖（2026-10-31）

本工作区新增 `console_config`，供主人私聊和已认证的控制台管理对话使用。先 `catalog/get` 查询，再 `stage` 展示脱敏后的改动；用户在同一会话下一条消息回复“确认”后 `confirm` 保存，无需确认码。每个用户和会话只保留最新的暂存，10 分钟过期，同一消息自确认、跨会话确认、重复确认均拒绝。安全模式继续禁止写入。

## 配置入口

| 配置 | 入口与行为 |
| --- | --- |
| 机器人全部可编辑字段 | `console_config` 的 `bot/update` 顶层补丁，涵盖主人、登录权限、Agent 权限、账号安全审核及连接设置；复用控制台校验和保存链路 |
| 所有模型用途、思考强度、启停、权重、后备、排序、分组与音视频参数 | `bot/update` 的 `model_roles`；提交完整用途映射，路由各自保存思考强度，删除用途键恢复继承 |
| 群设置与独立对话路由 | `group/update`，`target` 为群 ID；`chat_model.route` 是完整群独立路由，支持策略、权重、启停、后备和思考强度；`chat_model={}` 恢复机器人继承 |
| 提供商目录、地址、密钥与模型目录 | `provider` 的 `get/create/update/clone/delete/reorder`，更新只提交改动字段，未提交设置保留 |
| 插件普通设置与凭据 | `plugin/update`，非敏感设置按完整覆盖提交，省略密钥保留，`clear_secrets` 显式清除；内置联网搜索仍走统一搜索设置 |
| 下载缓存、历史媒体保留 | `media_cache/update`、`history_media/update`，支持保留天数、容量；历史媒体按新策略清理 |
| 控制台访问凭据 | `security/update`，修改后重新登录 |
| 控制台登录会话 | `sessions/get/delete/delete_all`，全部注销包含当前控制台登录会话 |
| 受信应用授权 | `trusted_apps/get/enable/create/update/rotate`；创建、轮换使用用户提供并自行保存的至少 32 字符密钥，避免生成只出现于脱敏聊天而无法领取的密钥 |
| 机器人创建、复制、删除 | `bot/create/clone/delete`；编辑和删除其他机器人前先切换管理对话，至少保留一台 |
| 日常接话、欢迎、行为与插件开关 | 原有 `bot_config` 保留；连接改动也采用后续消息“确认”，与新入口的暂存互斥 |
| 管理员名单、扩展开放范围、启动配置 | 原有 `bot_admins`、`extension_access`、`runtime_config`；各自身份和运行模式限制继续生效 |

## 脱敏与边界

- 配置结果递归遮住密钥、密码、令牌、请求头和 URL，包含嵌套对象和错误中的地址；配置调试日志只保留参数键，不记录提交值。
- 管理对话的实时回显和刷新历史也脱敏；内部执行保留原值，不能把脱敏占位符保存成新配置。
- 标识、时间戳、凭据预览和派生状态只读。浏览器主题是本地浏览器偏好，不属于服务端机器人配置。
- 原有单模型群覆盖保持优先选择行为；只有显式提交 `chat_model.route` 才替换该群完整路由。
- 配置写入失败返回错误，不报告成功；部分原有控制台保存路径会先热应用再持久化，错误会保留这一区别，需查询当前状态核对。
- 本次功能尚未部署。生产模型回放只使用合成上下文验证工具选择，不执行线上设置变更。
