# 机器人管理员

每台机器人有一个主人，另外可以指定若干管理员。管理员拿到全部管理权限，但不是主人：

| | 主人 | 管理员 | 普通用户 |
|---|---|---|---|
| 宿主命令（`host_access`，执行前经模型审核）、存储清理 | ✓ | ✓ | |
| 插件开关（`plugin_manage`）、机器人与群设置（`bot_config`）、模型配置 | ✓ | ✓ | |
| 扩展开放范围、机器人标记、屏蔽名单、表情包删除、仓库发布等其他管理工具 | ✓ | ✓ | |
| 「群 禁用」「提醒 列表」等主人指令、清空上下文、解除响应限制 | ✓ | ✓ | |
| 增减管理员（`bot_admins`） | ✓ | | |
| 称呼与亲疏、好感度、提醒订阅额度、主人通知、生图与群模型额度豁免 | ✓ | 照普通用户 | |

管理员在私聊里不受私聊准入名单限制，也不会被回复暂停和空转判断锁在机器人外面。

## 增减管理员

- 聊天里：主人直接说「把 12345 设为管理员」「取消 12345 的管理员」「现在有哪些管理员」，或引用对方的消息说「设为管理员」。只有主人能用，管理员不能再添加或撤下别人。
- WebUI：机器人设置的「主人账号」下方有「管理员账号」，需用 WebUI 管理员账户登录修改。

目标只认账号 ID，不按昵称；Telegram 可以写 `@用户名`，按发送者用户名核验，规则和主人一致。主人账号和机器人自己不能设为管理员；名单保存时自动去重、去空，并去掉主人。

## 权限边界

每次执行管理工具都按当前配置重新核验身份：取消管理员立即生效，已经加载的工具也不能继续用。工具面按主人装配，所以管理员看到的工具和主人相同（`bot_admins` 除外）；提示词里的身份行写明「主人指定的管理员，不是主人」，模型不会把管理员当主人称呼。

群主、群管理员这类平台身份不会自动成为机器人管理员。控制台的「管理员快速登录」指登录成 WebUI 管理员，和这里的机器人管理员无关，仍只接受主人私聊提交的验证码。WebUI 的群管理登录只能改群级配置，改不了管理员名单。

每多一个管理员，就多一个能以部署账号执行宿主命令的入口。命令审核按授权人自己的原话判断，管理员账号被盗时审核拦不住盗号者本人的请求，请只添加可信账号；不需要宿主权限的部署可以用安全模式。
