Talks like a human, works like an agent

Run your own AI right inside the chat apps you already use. It knows when to chime in and when to stay quiet in groups, remembers what matters, searches the web, parses links and files, and runs Skills, MCP, and local coding agents — all in a single binary with a built-in web console, keeping every piece of data on your machine.

Why Diana

No more choosing between a noisy group toy and a black-box framework that takes hours to configure.

Natural group presence

Knows when to chime in and when to stay quiet without being @-mentioned — no dead silence, no spam. Reply hours, personas, allow/deny lists, and tool permissions are tuned per group.

Built-in agent with safe mode

Uses file, shell, and browser tools, loads Skills and MCP servers on demand, and dispatches tasks to local Claude Code / Codex. Toggle safe mode to isolate host tools against prompt injection.

Single binary, fully self-hosted

No Python or Node runtime to wrangle — one command starts the service and built-in WebUI. Config, memory, and logs live in local SQLite with zero cloud dependency.

Multi-platform, no public IP needed

Run QQ, Telegram, WeChat, iMessage, and the built-in console in parallel with strict per-bot context isolation. Connects outbound so home and LAN setups work out of the box.

Long-term memory & notebook

Recent context, compacted summaries, structured facts, and deep history recall work in layers — remembering preferences and group rules while keeping token spend under control.

Web search, links & files

Researches time-sensitive questions via a sandboxed browser by default (or global Exa / Tavily providers), and parses Bilibili, YouTube, X, Xiaohongshu links plus PDF and Office files.

Vision, OCR & rendered visuals

Vision models and offline OCR let even text-only models read screenshots and stickers; tables, flowcharts, and sequence diagrams are rendered into clean images when text falls short.

Per-role model routing

Bind chat, vision, intent detection, and image generation to different providers and models — verified with a real request before saving, and switchable right from chat.

Every decision explained

See why every message was answered or skipped, which tools ran, and how many tokens were spent in the event center — no more guessing why a bot went silent.

Quick start

The installer detects your OS and architecture, downloads the latest stable build and verifies its SHA-256 against latest.json. Upgrades back up your data first and roll back automatically if the health check fails.

Linux / macOS
# the same command installs and upgrades
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Android Termux (ARM64)
# Run inside Termux; no root required
pkg install -y curl tar coreutils && curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Windows PowerShell
# the same command installs and upgrades
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex
Docker
# Run in your data directory; Docker with Compose must be installed and running
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/docker.sh | sh
Install with a skill (paste into an AI assistant that can run commands)
Read https://raw.githubusercontent.com/SuInk/Diana/main/skills/diana-install/SKILL.md and follow it to install the latest stable release of Diana on this machine.

1Run the installer

The initial admin username and password are printed once in the terminal — save them right away; reset anytime with diana passwd.

2Open the console

Visit 127.0.0.1:18080 and sign in with the admin account shown in the terminal.

3Connect channels and models

Configure your models and connect any platform in the web console, or start immediately with the built-in bot.

4Upgrading later

Upgrade from the console, or simply run the install command again; a failed upgrade restores itself.

Supported platforms

OneBot v11

Works with SnowLuma (recommended) and other OneBot implementations, in groups and direct messages, with per-group policy over how it replies.

Telegram

Official Bot API long polling. Outbound only, so no public address is needed.

QQ official bot

QQ Open Platform WebSocket gateway. Outbound connection, no public address needed.

WeChat

Tencent iLink Bot with QR-code login and outbound long polling; private chats only.

iMessage

Sent and received through BlueBubbles Server on a Mac, via webhook callbacks with optional polling fallback.

Built-in bot

No platform credentials required — chat or start a voice call right inside the console's Chat page to try everything immediately.

The first four external platforms connect outbound from your machine, so home or LAN setups work as-is; iMessage only needs your Mac to reach Diana — no public address required.
