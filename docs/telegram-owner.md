# Telegram 主人账号

在“机器人 → 接入 → 主人账号”中可以填写数字用户 ID、用户名或带 `@` 的用户名，例如 `1061423117`、`ruaneko`、`@ruaneko`。用户名比较不区分大小写，显示昵称不作为身份依据。

用户名只与 Telegram Bot API 消息中真实发送者的 `from.username` 匹配。匹配后，当前请求的权限检查使用同一发送者的数字 ID；保存的主人配置、消息发送目标和历史消息里的数字 ID 不会被改写。消息入队和恢复处理时保留平台发送者用户名。

匿名管理员、以频道身份发言、机器人账号、正文或引用里的 `@用户名` 都不会成为用户名核验来源。别人把显示昵称改成主人的用户名也不会获得权限。

主人权限适用于模型配置工具、主人关系判断和对应管理能力。管理员快速登录仍需主人主动私聊提交登录验证码；登录回执发到这条消息确认的数字 ID，不尝试通过用户名直接发私聊。

数字 ID 固定标识账号；用户名方案绑定的是当前持有该用户名的账号。变更或释放用户名后应及时更新主人配置，也可以改填数字 ID。其他平台继续沿用其原有账号 ID 规则，不按 Telegram 用户名匹配。
