# 提供商模型列表

模型以可换行的胶囊展示。左侧红色复选框控制启用，点击名称或胶囊空白也可切换；右侧铅笔编辑上下文窗口和能力，垃圾桶从目录移除该模型。编辑使用独立弹窗。所有操作先修改草稿，保存提供商后生效。

取消勾选保留模型和手动元数据；重新同步模型列表不会重新启用它。未设置启停字段的旧配置默认启用。停用模型不会出现在机器人模型候选或连通测试候选中，运行时也会排除它。已绑定的停用模型不再可用，可以重新勾选或调整机器人模型分配；已经发出的请求不会被强制中断。

停用默认模型后，保存时优先选择列表中的首个启用模型作为提供商默认值。允许全部停用，保存后不自动发起连通测试。删除与停用不同：删除会移除该目录项及其手动设置，之后同步可能重新发现上游模型。
