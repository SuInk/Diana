# 群内叫法自动学习

「机器人 → 上下文 → 记忆 → 自动学习群里的黑话」控制两条后台路径，复用长期记忆门控，不额外扫描聊天或新增提取调用。配置缺省开启；显式保存的 `slang_learning_enabled=false` 保持关闭，升级不会强制打开。

- **明确解释**：当前发言者解释或确认简称时，门控提交 `notebook_candidates`，包含词、释义、用词证据消息 ID 和确认消息 ID。例如先说 `uuu`，随后解释 `UbUntU`，可以保存 `uuu → Ubuntu`，无需联网或积累出现次数。
- **未知含义**：仍走 `unknown_terms`，同群至少两人、三次出现后联网查证；查不实继续等待，保留原有每日限额。

程序只接受本轮输入中的真实消息引用：确认必须来自当前批次、当前发言者、本群的非出站消息；已识别为 AI 的发言者或本轮 AI 概率达到 0.9 的发言者不自动确认释义。语义是否构成解释由模型判断，程序不靠关键词猜词义。机器人猜测、搜索结果不能单独作为确认依据。

明确解释和联网查实的词条都遵循「笔记本跟随机器人」设置：默认写入当前机器人的共用笔记本，群聊私聊共享；手动关闭后才按会话隔离。不会跨机器人配置档或跨平台合并，原有会话条目的读取优先级不变。

自动写入在存储事务内检查可读范围中的同名词和别名，包含已作废条目：已有条目不覆盖、不新增同名遮蔽、不复活；重复作业不增加版本。人工编辑仍使用原有修订流程。先处理确认候选，再处理未知词，同一候选不会在本轮再次进入联网查证。

该功能处理新进入后台记忆任务的消息，不主动回补历史聊天。`notebook_candidates` 只是提取协议；证据无效或数据库写入失败不代表已经记住，写入错误会记录到运行日志。
