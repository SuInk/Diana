多通道上下文

每个机器人保存独立的平台、账号、主人、人设和模型分配。OneBot v11 与 Telegram 同时运行时，回复始终回到来源通道。默认隔离会话与记忆；关闭隔离后可共享允许跨通道使用的长期事实，但不会改变发送路由。

模型配置

先同步模型列表，再填写默认模型

Provider 管理 Base URL、API Key 和协议。页面上方从服务端同步模型目录，下方填写或选择默认模型；机器人配置再将不同职责绑定到具体模型。

角色用途测试要求
对话最终回复、Agent 推理验证中文表达、工具调用和长上下文。
视觉普通图片、截图、历史图片发送真实图片，验证小字 OCR、界面结构和多图关系。
意图识别主动回复、回复抑制、关系判断验证低延迟、稳定结构化输出和边界案例。
图片生成文生图与图片编辑必须实际生成并返回图片，不能只测文本连通性。
默认启用

“识别机器人并自动不回复”默认打开，用于避免机器人之间循环对话；有明确业务需要时再关闭。

群聊策略

按实际加入的群逐个配置

群管理会通过 OneBot get_group_list 同步机器人加入的全部群，而不仅是已经存在本地配置的群。连接不可用时才回退显示 SQLite 中保存的群配置。

启用状态单独停止某个群，不影响其他群或私聊。
触发与主动回复显式 @、引用、触发词和主动回复语义路由分层判断；显式 @ 优先于引用。
回复时间支持同日、跨夜时间段和 IANA 时区；这属于群策略，不写入模型提示。
屏蔽账号名单只影响当前群，不影响同一用户在其他群或私聊中的消息。
人设与上下文群级提示、历史条数和回复长度可以覆盖机器人默认值。
工具覆盖每个群可跟随全局、强制开启或强制关闭具体工具和插件。

Agent 与工具

模型只看到当前场景允许的能力

Agent 运行器将结构化工具结果送回模型，直到得到最终回复或达到步数上限。工具注册表根据平台、关系权限、群配置和功能状态收敛。

内置联网搜索

联网搜索自带且不可安装/卸载。提示模型在时效性、事实核验、陌生实体和推荐类问题上优先检索。

提醒与订阅

一次性和周期任务统一持久化，控制台展示周期、下一次执行时间、来源和状态。

MCP 与 Skills

按配置发现外部扩展，受工作目录、允许列表、权限和超时限制。

图片工具

识别、生成和编辑分别授权；图片生成使用真实生图请求做健康测试。

安全边界

公网部署必须增加 HTTPS 和来源限制

  • WebUI 使用登录会话保护 API，并立即更换首次管理员密码。
  • OneBot 单独配置 access token，反向 WebSocket 两端保持一致。
  • config.yaml、模型 API Key、Bot Token 和平台 Cookie 不进入 Git。
  • 调试模式会记录完整上下文和工具参数，只在可信环境短期开启。
  • 公网入口放在 HTTPS 反向代理后，并限制管理端来源。
