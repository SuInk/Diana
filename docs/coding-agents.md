# 多个编码代理

在 WebUI「插件 → 编码代理」启用插件，然后在「额外编码代理」中点击「添加编码代理」。可以同时配置 Codex、Claude Code，或同一 CLI 的多个模型配置，最多添加 16 个。

每份配置包含名称、后端 CLI、模型、可执行文件、审批模式，以及可选的命令模板和密钥环境变量名。名称用于派活，例如 `codex-main`、`claude-review`。可以将其中一份设为默认；未指定代理的任务使用默认配置。

原有单代理配置保留为 `default`，无需迁移。没有额外默认代理时，原配置仍是默认。工作区白名单、运行时限、全局并发上限和 Claude 审批规则共用原有设置。同一个工作区仍不能同时执行两个任务；同时配置多个不代表同时运行，运行并发默认仍为 1。

## 在聊天里使用

- 「列出可用编码代理」：查看名称、后端、模型及默认配置。
- 「让 codex-main 在 diana 工作区修复这个 Bug」：指定配置提交后台任务。
- 「让 claude-review 检查另一个工作区的代码」：选择另一份配置。
- 「继续刚才的任务……」：支持续跑的任务继续使用原代理，即使默认代理已改变。

任务记录会保存代理名称。原配置被删除，或者后端、可执行文件、命令模板、模型发生变化，或工作区路径变化时，旧会话不能直接续跑，需要恢复原配置或提交新任务。查看进度、日志、取消任务不依赖当前配置有效。旧任务没有代理名称时按 `default` 处理。

## 登录与凭据

CLI 必须安装在运行 Diana 的环境中，可通过页面里的「安装 CLI」完成。可执行文件留空时从服务进程的 PATH 查找，必要时填写绝对路径。

每份额外配置默认使用 CLI 已有登录或进程环境中的凭据，不继承原配置的 API 密钥。可直接在每份配置的 API 密钥框填写并保存。也可在服务器环境中设置变量，再在「密钥环境变量名」填写变量名称，例如 `DIANA_CODEX_KEY`；不要填写密钥值。Codex 执行时对应注入 `CODEX_API_KEY`（同时兼容 `OPENAI_API_KEY`），Claude Code 对应注入 `ANTHROPIC_API_KEY`。指定变量不存在或为空时拒绝启动，避免意外使用其他凭据。自定义 CLI 使用自身环境配置。

多个配置共用服务用户的 CLI 登录环境；仅增加名称不会创建独立登录态或独立系统用户。需要不同 CLI 登录目录等设置时，可使用各自的启动脚本作为可执行文件。

## 后端边界

Claude Code 支持结构化进度、会话续跑和聊天审批。Codex 支持结构化命令进度与最终回答解析，不支持原会话续跑及聊天审批；配置时需明确选择关闭聊天审批，其预置命令会绕过 CLI 审批和沙箱。多配置功能不会改变这些后端能力。

编码代理仅机器人主人可调用，插件默认关闭。

## 本地真实 CLI 验证

默认测试使用模拟 CLI，不请求外部模型。已安装并配置 Codex 的开发环境可以显式运行：

```sh
DIANA_RUN_REAL_CODEX_SMOKE=1 go test ./model/assistant -run '^TestLocalRealCodexProfilesSmoke$' -v -count=1 -timeout 3m
```

该测试通过真实的编码工具选择命名 Codex 配置，在临时 Git 工作区读取一份固定内容文件，检查完成状态、最终回答及任务查询。会调用当前 CLI 配置的模型服务并消耗相应额度；不向真实聊天发送消息，测试结束后清理临时工作区。

## 在 WebUI 完成 Docker 配置

新镜像包含 npm、Git 与 CLI 所需运行库。已有 Docker 部署先升级镜像并重建容器，保留现有 `/app/data` 挂载，不需要额外挂载 Codex 配置目录。

1. 添加代理，选择 Codex 或 Claude，选择相应审批模式。
2. 填入 API 密钥，使用代理服务时填写 API 服务地址；官方服务地址可留空。密钥独立保存为插件凭据，读取接口不返回明文。留空保持已有值，清除按钮在保存后生效。
3. 勾选「自动创建持久工作目录」，保存设置。
4. 点击「检测环境」，未安装时点击「安装 CLI」，再点「测试连接」。这些操作使用已保存配置，测试会发起一次真实模型请求。
5. 在聊天里按代理名称派任务即可。CLI 和工作目录都位于数据库旁的数据目录，重建容器后自动发现；无需手工进入容器安装。首次安装需要服务器能访问 npm 官方包，过程通常需几分钟。

Codex 也可选择「使用 ChatGPT 登录」：先保存不带 API 密钥和自定义地址的配置，点击按钮，再刷新登录状态取得链接及一次性代码；在自己的浏览器完成授权后刷新，看到登录成功再测试连接。凭据按代理名称保存到数据目录，15 分钟未完成会自动结束；账户需要允许设备代码登录。更改代理名称后需重新登录。Claude 的 WebUI 目前使用 API 密钥方式，或复用运行用户已有登录，不提供浏览器登录回调。

自动工作目录用于新任务和新项目。需要修改已有项目时，取消自动目录并使用原有工作区白名单；容器外的现有文件仍需挂载进容器。安装器仅安装官方 `@openai/codex` / `@anthropic-ai/claude-code` 包，版本固定在 `model/assistant/coding_agent_setup.go`，随 Diana 发版核对更新；自定义 CLI 仍由部署者管理。本机不使用 Docker 时，自动安装需要已有 Node.js/npm。
