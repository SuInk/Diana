사람처럼 대화하고, 에이전트처럼 일합니다

이미 사용 중인 메신저 안에서 나만의 AI를 키워 보세요. 그룹에서는 멘션 없이도 분위기를 보고 발언과 침묵을 스스로 결정하고, 기억·웹 검색·링크/파일 분석·Skills / MCP·로컬 코딩 에이전트까지 한 번에 처리합니다. 웹 콘솔이 내장된 단일 바이너리로 모든 데이터가 내 기기에만 머뭅니다.

빠른 시작 문서 보기 라이브 데모 GitHub
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/docker/chromium-seccomp.json -o chromium-seccomp.json && docker run -d --name diana --security-opt seccomp="$PWD/chromium-seccomp.json" -p 18080:18080 -v diana-data:/app/data ghcr.io/suink/diana:latest

설치가 끝나면 http://127.0.0.1:18080을 열어 초기 설정을 진행하세요.

왜 Diana인가요

시끄러운 장난감 봇과 설정·디버깅이 막막한 블랙박스 프레임워크 사이에서 타협하지 마세요.

눈치 있는 자연스러운 참여

멘션 없이도 대화 흐름을 보고 끼어들 때와 조용히 있을 때를 판단합니다. 그룹별 응답 시간대, 페르소나, 허용/차단 목록, 도구 권한을 세밀하게 제어할 수 있습니다.

내장 에이전트 & 안전 모드

파일·명령어·브라우저 도구와 Skills / MCP를 필요할 때 불러오며 로컬 Claude Code / Codex에 작업을 맡길 수 있습니다. 안전 모드로 위험한 호스트 도구를 즉시 차단해 프롬프트 인젝션을 방지합니다.

단일 바이너리, 완전한 셀프 호스팅

Python이나 Node 런타임 없이 명령어 한 줄로 서비스와 내장 WebUI가 실행됩니다. 설정·기억·로그 모두 로컬 SQLite에 저장되며 클라우드 의존성이 없습니다.

다중 플랫폼 동시 실행, 공인 IP 불필요

QQ, Telegram, WeChat, iMessage와 내장 콘솔을 동시에 운영하고 봇별로 대화 컨텍스트를 격리합니다. 아웃바운드 연결 방식이라 가정용 인터넷과 내부망에서도 바로 동작합니다.

장기 기억과 검토 가능한 노트북

최근 대화, 압축 요약, 구조화된 사실, 장기 기록 검색이 계층적으로 동작해 토큰 비용을 아끼면서도 중요한 약속을 기억합니다. 노트북은 언제든 확인·수정할 수 있습니다.

웹 검색 및 링크·파일 분석

기본 샌드박스 브라우저로 최신 정보를 병렬 검색하고(전역 Exa / Tavily 설정 지원), Bilibili·YouTube·X·Xiaohongshu 링크와 PDF·Office 문서를 바로 이해합니다.

이미지 인식, OCR 및 도표 렌더링

비전 모델과 오프라인 OCR 덕분에 텍스트 전용 모델도 스크린샷과 스티커를 읽습니다. 표·플로우차트·시퀀스 다이어그램은 깔끔한 이미지로 렌더링해 전송합니다.

역할별 모델 라우팅

대화, 시각 이해, 의도 판단, 이미지 생성마다 최적의 공급자와 모델을 따로 연결하고 저장 전 실제 요청으로 검증합니다. 채팅 중 모델 전환도 가능합니다.

모든 결정 과정을 투명하게 기록

각 메시지에 왜 답했는지, 왜 넘겼는지, 어떤 도구를 실행했고 토큰을 얼마나 썼는지 이벤트 센터에서 한눈에 확인할 수 있습니다.

빠른 시작

설치 스크립트가 OS와 아키텍처를 자동 감지해 최신 안정 버전을 내려받고 latest.json의 SHA-256을 검증합니다. 업그레이드 전 자동 백업과 장애 시 자동 롤백을 지원합니다.

Linux / macOS
# 설치와 업그레이드 모두 같은 명령어
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Android Termux (ARM64)
# Termux 내에서 실행 (루팅 불필요)
pkg install -y curl tar coreutils && curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Windows PowerShell
# 설치와 업그레이드 모두 같은 명령어
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex
Docker
# 데이터를 저장할 디렉터리에서 실행 (Docker Compose 필요)
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/docker.sh | sh
Skill로 설치 (명령을 실행할 수 있는 AI 어시스턴트에 붙여넣기)
Read https://raw.githubusercontent.com/SuInk/Diana/main/skills/diana-install/SKILL.md and follow it to install the latest stable release of Diana on this machine.

1설치 명령 실행

초기 관리자 아이디와 비밀번호는 터미널에 한 번만 표시되므로 즉시 보관하세요. 분실 시 diana passwd로 재설정할 수 있습니다.

2콘솔 열기

127.0.0.1:18080에 접속해 터미널에 표시된 관리자 계정으로 로그인합니다.

3모델과 채널 연결

WebUI에서 모델과 원하는 플랫폼을 연결하거나, 별도 설정 없이 내장 봇으로 바로 시작해 보세요.

4추후 업그레이드

콘솔에서 바로 업데이트하거나 설치 명령을 다시 실행하세요. 실패 시 이전 상태로 자동 복구됩니다.

지원 플랫폼

OneBot v11

SnowLuma(권장) 등 OneBot 구현체와 연동하여 그룹·개인 채팅 및 그룹별 정책 제어를 지원합니다.

Telegram

공식 Bot API 롱 폴링 기반 아웃바운드 연결로 공인 IP가 필요 없습니다.

QQ 공식 봇

QQ 오픈 플랫폼 WebSocket 게이트웨이 아웃바운드 연결을 지원합니다.

WeChat

Tencent iLink Bot QR 로그인과 아웃바운드 롱 폴링을 지원합니다(1:1 채팅 전용).

iMessage

Mac의 BlueBubbles Server를 통해 웹훅과 선택적 폴링 보조로 메시지를 주고받습니다.

내장 봇

외부 플랫폼 인증 없이 콘솔 채팅 페이지에서 바로 대화하거나 음성 통화를 시작할 수 있습니다.

앞선 4개 외부 플랫폼은 아웃바운드 연결로 가정·내부망에서 그대로 동작하며, iMessage도 Mac이 Diana에 접근할 수 있으면 공인 IP 없이 사용할 수 있습니다.
