Schreibt wie ein Mensch, arbeitet wie ein Agent

Betreibe deine eigene KI direkt in den Chat-Apps, die du täglich nutzt. Sie erkennt in Gruppen, wann sie mitreden und wann sie still bleiben sollte, merkt sich Wichtiges, sucht im Web, analysiert Links und Dateien und nutzt Skills, MCP sowie lokale Coding-Agents — alles in einer einzigen Binärdatei mit Web-Konsole, während sämtliche Daten auf deinem Rechner bleiben.

Warum Diana

Schluss mit der Wahl zwischen einem nervigen Gruppen-Spielzeug und einem schwer wartbaren Blackbox-Framework.

Natürliche Gruppenpräsenz

Weiß ohne `@`, wann es sich einbringen und wann es still bleiben sollte — kein Totstellen, kein Spam. Antwortzeiten, Personas, Listen und Tool-Rechte lassen sich pro Gruppe steuern.

Integrierter Agent & Sicherheitsmodus

Nutzt Datei-, Befehls- und Browser-Tools, lädt Skills und MCP-Server bei Bedarf und delegiert an lokales Claude Code / Codex. Der Sicherheitsmodus sperrt Host-Tools gegen Prompt-Injection.

Single Binary, voll selbstgehostet

Kein Python- oder Node-Setup nötig — ein Befehl startet Dienst und eingebaute WebUI. Konfiguration, Gedächtnis und Logs liegen lokal in SQLite ohne Cloud-Zwang.

Multi-Plattform ohne öffentliche IP

QQ, Telegram, WeChat, iMessage und die integrierte Konsole laufen parallel mit strikter Kontexttrennung pro Bot. Ausgehende Verbindungen klappen direkt im Heimnetz.

Langzeitgedächtnis & Notizbuch

Aktueller Kontext, komprimierte Zusammenfassungen, strukturierte Fakten und Verlaufssuche arbeiten geschichtet — so bleiben Absprachen präsent und Token-Kosten im Griff.

Websuche, Links & Dateien

Recherchiert Aktuelles standardmäßig über einen isolierten Browser (oder globale Exa-/Tavily-Anbieter) und wertet Links von Bilibili, YouTube, X, Xiaohongshu sowie PDF- und Office-Dateien aus.

Vision, OCR & gerenderte Grafiken

Vision-Modelle und Offline-OCR lassen auch reine Textmodelle Screenshots und Sticker lesen; Tabellen, Fluss- und Sequenzdiagramme werden sauber als Bild gerendert.

Modell-Routing nach Aufgabe

Chat, Vision, Absichtserkennung und Bilderzeugung erhalten jeweils eigene Anbieter und Modelle — vor dem Speichern echt getestet und direkt im Chat umschaltbar.

Jede Entscheidung nachvollziehbar

Im Ereigniscenter siehst du, warum jede Nachricht beantwortet oder ignoriert wurde, welche Tools liefen und wie viele Token verbraucht wurden.

Schnellstart

Der Installer erkennt OS und Architektur, lädt die aktuelle stabile Version herunter und prüft SHA-256 gegen latest.json. Upgrades sichern zuvor deine Daten und rollen bei Fehlern automatisch zurück.

Linux / macOS
# derselbe Befehl installiert und aktualisiert
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Android Termux (ARM64)
# in Termux ausführen; kein Root erforderlich
pkg install -y curl tar coreutils && curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Windows PowerShell
# derselbe Befehl installiert und aktualisiert
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex
Docker
# im Datenverzeichnis ausführen (Docker Compose erforderlich)
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/docker.sh | sh
Per Skill installieren (in einen KI-Assistenten mit Terminalzugriff einfügen)
Read https://raw.githubusercontent.com/SuInk/Diana/main/skills/diana-install/SKILL.md and follow it to install the latest stable release of Diana on this machine.

1Installer ausführen

Admin-Benutzername und Passwort werden einmalig im Terminal ausgegeben — direkt sichern; jederzeit zurücksetzbar per diana passwd.

2Konsole öffnen

Rufe 127.0.0.1:18080 auf und melde dich mit dem im Terminal angezeigten Konto an.

3Modelle & Kanäle verbinden

Hinterlege deine Modelle und verbinde beliebige Plattformen in der WebUI — oder probiere sofort den integrierten Bot aus.

4Später aktualisieren

Direkt in der Konsole updaten oder den Installationsbefehl erneut ausführen; bei Fehlern erfolgt automatische Wiederherstellung.

Unterstützte Plattformen

OneBot v11

Funktioniert mit SnowLuma (empfohlen) und anderen OneBot-Clients für Gruppen, Direktnachrichten und Gruppenregeln.

Telegram

Offizielles Bot-API-Long-Polling, rein ausgehend — keine öffentliche Adresse erforderlich.

QQ Official Bot

Ausgehendes WebSocket-Gateway der QQ Open Platform ohne öffentliche IP.

WeChat

Tencent iLink Bot mit QR-Code-Login und ausgehendem Long Polling (nur Privat-Chats).

iMessage

Über BlueBubbles Server auf einem Mac per Webhook mit optionalem Polling-Fallback.

Integrierter Bot

Keine externen Zugangsdaten nötig — direkt im Chat-Tab der Konsole schreiben oder Sprachanrufe starten.

Die ersten vier externen Plattformen verbinden sich ausgehend von deinem Rechner und laufen direkt im Heimnetz oder LAN; bei iMessage muss lediglich dein Mac Diana erreichen können — keine öffentliche IP nötig.
