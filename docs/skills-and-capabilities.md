# Skills 与能力配置

Diana 把可复用流程和实际执行能力分开：Skill 描述工作流，Plugin/MCP 提供工具。Skill 的 `SKILL.md` 可以携带参考资料、模板和脚本，但不能自行扩大会话权限。

## 设置作用域

插件或 Skill 的设置项可以在 `PluginSettingSpec` 中声明：

- `scopes`: `bot`、`group`、`user`，分别表示机器人、群和个人作用域。
- `configure_by`: `owner`、`group_admin`、`member`，表示哪些角色可以修改。
- `secret`: 凭据只能由主人配置，永远不能写入群级覆盖。
- `global_only`: 进程级资源不能按群覆盖。

没有声明 `scopes` 和 `configure_by` 的旧设置保持兼容：非凭据、非全局设置可被群级覆盖；机器人级设置仍由主人管理。

## 权限边界

主人可以配置所有已经声明的设置。群主和群管理员只能修改作用域为 `group` 且允许 `group_admin` 的设置。普通成员只能修改作用域为 `user` 且明确允许 `member` 的设置。

群级设置只能收窄主人已经开放的能力，不能打开未安装、未启用或高风险工具。安装、替换、卸载 Skill，以及网络、代码执行、外部写入等能力边界仍由主人控制。

运行时的生效顺序是：机器人设置 → 群设置 → 用户设置 → 当前会话临时覆盖。每一层都要经过设置项自己的作用域和角色策略校验。
