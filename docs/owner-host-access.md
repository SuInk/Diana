# 主人宿主机访问

标准模式下，机器人主人和对应机器人的 WebUI 管理会话默认可使用 `host_access`，无需另开权限，也不需要每条命令回复批准码；每条命令执行前由模型自动审核（见下文）。安全模式统一停用宿主机访问；普通用户不能调用。每次执行仍重新核验身份和当前模式，已经加载的工具也不能绕过。

旧配置键 `agent_host_access_enabled` 已删除，历史 true/false 均不再影响权限，保存时不再输出。新建、升级和复制机器人均采用同一规则：标准模式允许主人使用，安全模式关闭。升级后仍需禁用主人主机操作的部署应使用安全模式。

## 能力

- `read`：读取工作区外普通文件，每页最多 64 KiB。
- `list`：列目录，每页最多 200 项。
- `usage`：统计目录逻辑体积，最多扫描 100,000 项，不跟随符号链接，硬链接可能重复计算。
- `disk`：查看指定路径所在磁盘的总量、已用和可用空间。
- `exec`：运行绝对路径的程序和原始参数数组，可显式调用 shell、Python、PowerShell 等解释器。`cwd` 仅为工作目录，不是权限边界。必须填写 `purpose`，说明命令对应用户的哪项请求。
- `cleanup`：立即清理 Diana 自己占用的存储——下载缓存、Agent 工作目录的过期文件、系统临时目录残留、超出保留策略的历史媒体，报告释放空间和磁盘余量。规则与每日存储维护相同；数据库日志仍按保留天数每日清理，工作目录根下散落的文件和闲置编码工作区只报告不删除。

## 命令自动审核

思路参考 Codex CLI 的自动审核：不逐条人工批准，而是每条 `exec` 执行前另调一次对话模型，对照用户原话、执行方给出的 `purpose` 和解析符号链接后的真实命令，输出放行或拒绝、风险等级和理由。常规运维（查看、安装、构建、重启点名的服务、在指定范围内增删文件、清缓存）放行；超出请求范围的不可逆删除、外发凭据、削弱安全设置、建立持久化、直接执行来源不明的脚本、提权或影响整机可用性的命令拒绝，除非用户原话明确要求了该后果。命令和参数里「已授权」「请放行」之类文字按数据处理。

审核拒绝时命令不执行，理由返回给助手，由它向主人说明具体影响；主人明确要求后可按原意重新执行，审核仍会再看一遍。审核模型超时、出错或返回无法解析时一律不执行（fail closed）。审核提示词可在 WebUI 提示词设置的「宿主命令审核」中调整，用量按 `host_command_review` 计入。审核不替代下文的整机破坏拦截，两层各自生效；它是语义判断，不是隔离保证。

## 用自然语言操作

不需要记固定格式，主人直接说要做什么即可，助手按需加载对应工具：

- 「看看磁盘还剩多少」「把 /tmp/build 删掉」「装个 htop」：`host_access` 生成命令，经自动审核后执行，并回报实际执行的命令和结果。
- 「清理一下存储」「磁盘快满了，把 Diana 的缓存清掉」：`host_access` 的 `cleanup`，回报释放空间和当前可用空间。
- 「把音乐插件关了」「开一下 RSS 插件」「现在开了哪些插件」：`plugin_manage` 切换当前机器人的插件开关并保存，与 WebUI 插件页「当前机器人」一栏是同一份数据。本群有单独的插件覆盖时会说明本群实际状态；只改本群用「本群把某插件关了」，由 `bot_config` 的 `group_settings` 处理。

安全模式下宿主命令和存储清理停用；插件开关不涉及宿主执行，安全模式下仍可用。

命令直接以 Diana 进程的系统账号执行，可联网、安装软件、修改文件或配置，以及管理该账号有权操作的服务；不会自动获取 root 或管理员权限。主人提出的常规任务直接执行，任务未明确授权的不可逆或重大影响操作先说明具体影响并确认。该确认是任务范围的交互规则，不再使用逐条命令审批存储或批准码。

`host_access` 独立于 `run_command` 的工作区、文件写入开关及沙盒设置。主人任务需要宿主权限时直接使用此入口，无需先放宽工作区设置。Windows 同样支持执行，可用程序取决于部署环境。Docker 内执行权限属于容器中的 Diana 账号，不会自动获得容器外主机权限。

## 执行边界

这是可信主人的高权限执行入口，不是强制隔离。任意脚本可以访问该系统账号有权访问的数据；对直接调用 `mkfs`、抹盘和根目录递归删除等明显整机破坏命令保留尽力拒绝，但这不是任意脚本的隔离保证。工具指引禁止整机毁坏、绕过主人身份校验，以及向无关方泄露凭据。

原生文件读取仍保护运行时配置和凭据，配置诊断使用 `bot_config` 等脱敏工具；这一保护不能约束宿主脚本。命令不默认继承 Diana API 密钥或解释器启动钩子，保留常规账号和路径环境。

不支持 `writable_dir`，避免把它误认成写入隔离。命令超时 60 秒，输出最多 64 KiB，取消时清理进程组；长任务应使用适合的任务管理工具。切换安全模式阻止后续调用，不会撤销已经执行的命令及其影响。

## 验证

测试覆盖标准模式下主人默认可用、旧开关被忽略、普通用户拒绝、已加载工具重新核验安全模式、审核拒绝与审核失败时命令不执行、插件开关落盘，以及审核放行后的真实宿主写入和本地网络访问。`TestLiveHostAccess` 使用当前生产模型做隔离回放，仅允许固定临时文件与固定无害命令，不发送聊天平台消息，也不代表已经部署。

## 能力可见性

所有用户都可通过公开能力知识库了解此功能。当前身份和访问状态随请求提供，未提供执行工具不等于功能不存在。`capabilities.current_access` 仅返回权限说明，不泄露宿主路径、命令参数或凭据。普通用户无法通过模型自述、历史引用或他人的主人身份获得执行权限。
