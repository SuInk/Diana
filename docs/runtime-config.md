# 启动配置与访问地址

「设置 → 启动配置」集中展示启动时就定下来的那层配置，以及本机的访问地址。机器人设置和模型以数据库为准，不在这里。

## 配置来源

| 来源 | 能否在控制台改 | 能否让机器人改 | 生效时机 |
| --- | --- | --- | --- |
| 命令行参数（目前只有 `--config`） | 否 | 否 | 启动时 |
| 环境变量 | 否，只显示有没有设置，密钥类只显示「已设置」 | 否 | 启动时 |
| config.yaml 的 `server` / `storage` / `admin` / `update` / `llm_runtime` | 除初始管理员和两项页面管的保留策略外都可改 | 和控制台相同 | 写入文件，重启后生效 |
| config.yaml 的 `bot` / `llm` | 在对应页面改，数据库优先 | 走各自的工具 | 立即 |

每项会标出当前值来自「配置文件」还是「默认值」。文件已改、进程还没重启的项标「待重启」，并显示运行中的值。

## 可改范围

- **只读**：初始管理员（只在首次启动时用，之后在「访问安全」里改），以及下载缓存和历史媒体的保留策略（在各自页面保存后以页面为准）。
- **控制台可改、标「谨慎」**：监听地址、端口、前端目录、数据库路径、媒体目录、源码目录、更新工作目录。保存前要单独确认；不会替你搬数据。改端口时 Docker 端口映射和 OneBot 反连地址要一起改。改错连不上控制台时，直接编辑配置文件改回来。
- **控制台可改**：信任的反向代理、日志文件、本地媒体对外地址、更新开关，以及下面这些数值项。改信任代理或更新开关时会再确认一次。
- **机器人**（主人私聊，`runtime_config` 工具）：能改的范围和控制台相同。机器人要先向主人复述改动（「谨慎」项还要说清后果），得到同意后才写入，返回结果附带风险提示；改坏了让它改回原值再重启即可。安全模式下不能改，只能查看。

写回保留文件里原有的注释和其它段。启动时没有配置文件的，第一次保存会创建 `data/config.yaml`（权限 0600）。

## 访问地址探测

列出本机启用网卡上的地址，分成本机（回环）、局域网（含 100.64.0.0/10，即 Tailscale、运营商级 NAT）、网卡上的公网地址和链路本地。按监听地址拼出可以直接打开的 URL。在 Docker 里跑时，显示的是容器内部的地址。

公网出口地址要访问外部服务（ipify、ifconfig.me、icanhazip 依次尝试），所以默认不查，要点「探测公网地址」才查，结果缓存 5 分钟。它只能说明从外面看是哪个地址，能不能从外网连进来还取决于端口映射和防火墙。

接口：`GET /api/system/runtime-config`、`PUT /api/system/runtime-config`（`{"values": {"storage.log_retention_days": "30"}}`，空字符串表示删掉这项、回到默认值）、`GET /api/system/network?public=1&force=1`。
