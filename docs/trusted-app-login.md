# 受信应用私聊登录

受信应用可以复用 Diana 的主人私聊确认能力。它不是 OAuth/OIDC 服务，也不会向应用签发 Diana 管理台会话。应用自行维护管理员授权、登录会话、退出和撤销。

## 启用

默认关闭。设置 `DIANA_TRUSTED_LOGIN_APPS_FILE` 为服务端 JSON 文件路径并重启 Diana。文件示例：

```json
[
  {
    "id": "ruhua",
    "name": "入画管理台",
    "secret_sha256": "替换为应用密钥的 SHA-256 十六进制摘要",
    "profile_id": "替换为机器人配置 ID"
  }
]
```

为每个应用生成独立的随机密钥（至少 32 字节熵），例如 `openssl rand -hex 32`；将原始密钥安全地配置在应用后端，用 `printf '%s' "$APP_SECRET" | shasum -a 256` 计算摘要。不要将密钥提交到仓库、放入前端、URL 或日志。配置文件只允许服务账号读取。应用 ID 需满足 `[a-z][a-z0-9_-]{0,47}`，最多 32 个应用。删除应用或轮换摘要后重启生效，所有未完成配对也会失效；这不会撤销应用已建立的会话。

Diana 必须初始化管理员密码；指定机器人必须启用、配置主人并开启管理员快速登录。确认仅接受该机器人的主人私聊，群聊不生效。第一版不支持普通成员登录。

## 服务端接口

两条接口均使用 HTTPS + HTTP Basic：用户名为应用 ID，密码为原始应用密钥。仅可信同机开发可以使用 HTTP。不要从浏览器直接调用。控制台 Cookie 不能代替应用凭证，响应统一 `Cache-Control: no-store`。

### POST /api/auth/apps/pair

无需请求体。成功响应示例：

```json
{
  "app_name": "入画管理台",
  "code": "123456",
  "command": "登录应用 ruhua 123456",
  "poll_token": "64位十六进制随机查询凭证",
  "expires_in_seconds": 300
}
```

应用后端保管 `poll_token`，将请求绑定到发起浏览器的随机、HttpOnly 配对 Cookie。浏览器只显示应用名称、完整 `command` 和倒计时。提示用户只确认本人发起的登录，不要转发他人的登录指令。不要仅显示六位数字；裸数字只属于原有控制台登录。

每个应用每 3 秒最多创建一次、最多 8 个待完成请求，所有应用共最多 128 个。应用后端仍应按来源 IP 限流，避免匿名请求占满配额。

### POST /api/auth/apps/pair/status

请求：`{"poll_token":"创建时得到的查询凭证"}`。建议每 2 秒请求一次。同一配对最快每秒一次，过快返回 429 和 Retry-After。

待确认：`{"approved":false,"expires_in_seconds":298}`。

不存在、过期、已领取或属于其他应用：`{"approved":false,"expired":true}`。

确认后首次领取：

```json
{
  "approved": true,
  "app_id": "ruhua",
  "identity": {
    "profile_id": "bot-id",
    "platform": "onebot-v11",
    "user_id": "10001",
    "confirmed_at": "2026-10-17T00:00:00Z"
  }
}
```

身份键为 `(profile_id, platform, user_id)`；平台值沿用机器人配置中的平台标识，勿依赖显示名称或 Telegram 用户名。应用校验应用 ID 和允许的身份后建立自己的会话。平台身份由已校验的消息事件取得，不接受请求方自报用户 ID。

成功领取原子地消费配对；并发请求只有一个成功。成功响应如果在网络中丢失，必须重新发起登录，不重放结果。确认后配对仍受原始 5 分钟有效期约束。没有仅凭短验证码领取结果的接口。

错误：400 无效请求，401 无效应用凭证，429 请求过快，503 当前机器人或密码保护不可用。网络错误允许在有效期内重试；遇到 expired 应重新创建。

## 隔离与信任边界

第三方配对和控制台配对使用独立内存存储、指令及领取接口；第三方确认不签发任何控制台 Cookie。私聊回执说明应用名称和 ID。创建、确认、领取事件进入操作日志，不记录验证码、应用密钥或查询凭证。

应用名称来自受保护配置，不接受请求临时指定。指定应用的持密钥后端属于信任边界；密钥泄漏可发起该应用的配对，但仍需主人私聊确认。Diana 无法撤销应用自身会话，应用需要提供退出、有效期和管理员撤销措施。服务重启使尚未完成的配对失效。

已有的控制台私聊登录、手动领取和账号密码登录保持不变。本功能无 LLM 调用，无需模型回放；验证使用模拟平台事件和实际 HTTP 路由。
