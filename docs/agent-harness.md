# Diana Agent 运行钩子

本次参考 [Pi Agent Core 的生命周期接口](https://github.com/earendil-works/pi/blob/6c2fd73b0c545a4034672cb60e34d53e035dd751/packages/agent/README.md)，在现有 Go Runner 上补充宿主钩子，不引入 Node.js、Pi 子进程或第二套会话存储。现有中途补充、工具预算、只读搜索并行、权限与媒体处理继续使用 Diana 实现。

## 生命周期

可信调用方通过 `agent.Request.Hooks` 提供 `RunHooks`：

| 钩子 | 时机与行为 |
| --- | --- |
| `PrepareRequest` | 每次模型请求前，包括预算耗尽后的强制收尾。返回的上下文只用于这次请求，不累计写入原始会话；出错则不调用模型。 |
| `BeforeToolCall` | 工具名称已解析、参数已整理且配置权限允许后。返回错误阻止执行，模型得到明确失败结果。不能放开注册表拒绝的操作。 |
| `AfterToolCall` | 执行结果已经遮蔽凭据并截断后，观察成功、失败或被拦截的结果。不改写原始执行结果。 |
| `BeforeFinish` | 普通正文、结构化收尾、静默携带的正文、终结工具与预算兜底都检查。返回反馈则拒绝草稿，保留已完成工具结果，继续模型循环。最多两次补查机会；无法继续或检查出错时返回 `ErrFinishRejected`，不交出被拒绝的正文。 |

这不是 Pi API 的逐字翻译：`BeforeFinish` 专门审核最终候选，不等于 Pi 每个模型轮次的 `finishTurn`。并行工具共用的前后钩子串行调用，但工具本身仍可并行；回调到达顺序不保证是请求顺序，模型工具结果仍按原始请求顺序排列。回调必须响应 context 取消，不得修改传入的只读数据，也不得递归启动同一个 Runner。

收尾检查不会撤销工具已经产生的外部效果，也不会撤回已流式投递的文字。需要阻断式事实检查的调用方必须缓冲候选正文，检查通过后才对外发送。不能把输出检查当成写操作授权。

## 主回复链路

主回复使用 `AfterToolCall` 收集本轮实际结果，用 `PrepareRequest` 在模型请求的动态尾部提供有限的执行摘要：

- 工具名、成功/失败/未执行状态。
- 操作、群范围与账号目标；不复制任意参数、凭据、查询正文或工具全文。
- 最多最近 12 条，以及总条数和省略条数。
- 原始稳定前缀不变，不拆开原生工具调用与结果，不将摘要保存为聊天消息或长期记忆。

摘要不是事实裁判。工具返回成功不能证明答案中的每个数字正确；没有本轮调用也不代表先前已核实的事实无效。默认主回复没有新增一个自动判断任意文本真假的模型调用。`BeforeFinish` 是业务规则的接入点，不能仅凭工具调用次数判断答案是否可信。

## 历史查询范围

`chat_history search` 支持 `group_id` 配合 `scope=current`，在跨群开关、私聊主人或共同群成员校验通过后，真正查询目标群。返回值带 `scope` 和单群查询的 `group_id`。分页游标绑定实际目标会话，不能在不同群之间复用。

指定单群同时使用 `all_groups` 会报错。其他未支持指定群的操作收到 `group_id` 时也明确报错，避免无声查回当前私聊。跨群 search 缺少关键词不能悄悄退回当前会话时间线。历史工具另提醒：机器人旧回复只证明它说过那段话，资料与执行结论需要原始证据。

私聊出站记录的 `UserID` 是归档用的聊天对象，不能直接作为发言者。历史工具与结构化摘要现在按出站标记识别机器人，以记录的 `SelfID`（缺失时才使用同平台配置）展示作者账号；无法确认账号则留空，不借用聊天对象的身份。原始归档键和引用消息作者保持不变。

串行原生工具失败的 `ToolError` 标记同步修正，失败正文不再被编码成成功工具消息。

## 验证

自动测试覆盖零调用草稿的拒绝、保留已完成操作、重试上限、强制收尾和终结工具、回调错误、并行拦截、原生工具失败标记，以及指定群的权限与私聊旧回复隔离。

`TestLiveHistoryScopeReplay` 使用当前部署模型和人设配置、隔离的历史夹具，重现“私聊里有旧统计、目标群有本人原话”的场景。它不加载发送工具、不写生产库；其中的任务专用收尾检查只要求本轮读取指定原始记录，不是通用事实核验器。通过私有配置文件启用：

```sh
DIANA_LIVE_LLM=1 \
DIANA_TEST_LLM_CONFIG=/private/path/provider.json \
DIANA_TEST_BOT_CONFIG=/private/path/bot.json \
go test ./model/assistant -run '^TestLiveHistoryScopeReplay$' -count=1 -v
```

模型回放需要结合日志人工核对：读到证据不代表模型对检索完整性或人物身份的解释一定正确。Pi 本身也不提供普遍的防幻觉保证。
