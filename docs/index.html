快速开始

一条命令，启动 Diana

安装器自动识别系统与 CPU 架构，下载完整 Release 包并校验 SHA-256。安装前备份已有数据，切换版本后完成健康检查，失败自动回滚。

curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex
git clone https://github.com/SuInk/Diana.git && cd Diana
cp docker-compose.yml docker-compose.local.yml   # 填入 token 与 LLM 配置
docker compose -f docker-compose.local.yml up -d --build

完成后打开 http://127.0.0.1:18080，用终端显示的首次登录凭据进入控制台。重复执行同一条命令即可升级。

部署参数与其他方式

核心能力

消息接入、模型决策和运维状态都能看见

能力都在控制台里可配可关，不需要改代码，也不需要为每个功能各装一个插件。

多通道同时在线

OneBot v11 与 Telegram 并行运行，回复回到来源通道；会话和记忆可按需隔离或共享。

模型职责拆分

对话、识图、意图识别和图片生成分别绑定 Provider 与模型，保存前用真实请求验证。

内置联网搜索

联网搜索无需安装插件，面对时效性内容和陌生事实时可以先检索再回答。

看得懂图里的字

图片可同时走视觉模型与 OCR；对话模型不支持看图时，也能只收识别后的文字。

群级回复策略

为每个群独立设置回复时段、屏蔽名单、触发词、人设、等级门槛和工具权限。

长期记忆与检索

近期上下文、压缩摘要、结构化事实和超长历史检索分层工作，控制 token 消耗。

Agent、Skills 与 MCP

内置 Agent 循环可调用文件、命令与浏览器工具，并按需装载 Skills 和 MCP 服务。

完整事件审计

记录为什么回复、为什么不回复、最终结果与 token；调试模式还原上下文和工具调用链。
