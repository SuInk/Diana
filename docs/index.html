一键安装

一条命令，启动 Diana

安装器自动识别系统与 CPU 架构，下载完整 Release 包并校验 SHA-256。安装前备份已有数据，切换版本后完成健康检查。

curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex

完成后打开 http://127.0.0.1:18080，使用终端显示的首次登录凭据进入控制台。

部署参数与其他方式

核心能力

消息接入、模型决策和运维状态都能看见

多通道同时在线

QQ 与 Telegram 并行运行，回复回到来源通道；会话和记忆可按需隔离或共享。

模型职责拆分

对话、识图、意图识别和图片生成分别绑定 Provider 与模型，并提供对应的真实测试。

内置联网搜索

联网搜索无需安装插件，面对时效性内容和陌生事实时可以先检索再回答。

群级回复策略

为每个群独立设置回复时间、屏蔽 QQ、触发词、人设、等级限制和工具权限。

长期记忆与检索

近期上下文、压缩摘要、结构化事实和超长历史检索分层工作，控制 token 消耗。

完整事件审计

记录为什么回复、为什么不回复、最终结果与 token；调试模式还原模型上下文和工具调用链。
