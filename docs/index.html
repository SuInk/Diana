核心能力

从消息接入到运维都能看见

QQ 与 Telegram 同时在线

两个通道并行运行，回复始终回到来源通道；会话和记忆可选择隔离或共享。

模型职责拆分

对话、识图、意图识别和图片生成可分别绑定 Provider 与模型，并提供对应的真实测试。

内置联网搜索

联网属于内置工具，不需要安装插件。时效性和陌生事实问题可先检索再回答。

群级策略

每个群独立配置回复时间、屏蔽 QQ、触发词、人设、等级限制和工具权限。

长期记忆

近期上下文、压缩摘要、结构化事实和超长历史检索分层工作，避免无限堆积 token。

完整事件审计

显示为什么回复、为什么不回复、最终结果与 token；调试模式呈现模型上下文和工具调用链。

快速开始

不再手工挑选和下载 Release 包

安装器自动识别操作系统与 CPU 架构，下载完整包和 SHA256SUMS，校验后安装为用户服务，并等待健康检查通过。以后重复执行同一条命令即可升级，数据库和旧运行文件会先备份。

Linux / macOS 
curl -fsSL https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.sh | sh
Windows PowerShell 
irm https://raw.githubusercontent.com/SuInk/Diana/main/scripts/install.ps1 | iex
安装完成

终端会打印控制台地址和首次登录凭据。默认地址是 http://127.0.0.1:18080。
