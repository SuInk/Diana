像真人一样聊天，像 Agent 一样干活

把 AI 养在你常用的聊天软件里。群里不用 @ 也会看气氛搭话，日常能记事、看图、扒链接、点歌， 办事能联网、调 Skills / MCP 甚至派本机编码代理改代码；单二进制自带控制台，配置、记忆与决策全部留在你机器上。

为什么是 Diana

不用在「只会水群的玩具 Bot」和「难配难查的黑盒框架」之间妥协。

懂分寸的主动搭话

群里不用 @ 也能判断何时插话、何时保持安静，不装死也不刷屏；按群独立配置回复时段、人设、黑白名单与工具权限。

内置 Agent 与安全模式

内置文件、命令与浏览器工具，按需装载 Skills 与 MCP，并可派活给本机 Claude Code / Codex；开启安全模式一键隔离高危工具，群聊防注入。

单二进制，完全自托管

不用折腾 Python 或 Node 环境，一条命令跑起服务和内置 WebUI；配置、记忆、日志全部落在本机 SQLite，不依赖任何云端托管。

多平台同时在线，免公网

QQ、Telegram、微信、iMessage 与内置控制台并行运行，回复始终回到来源通道；家庭宽带或内网出站直连，会话按机器人严格隔离。

长期记忆与可审笔记本

近期对话、压缩摘要、结构化事实与超长历史分层召回，既记得住群规与约定，又稳控 token 消耗；笔记本随时可审可改。

联网搜索与链接/文件解析

默认通过沙盒浏览器并行检索时效信息，也可全局切换 Exa、Tavily 等搜索源；B 站、YouTube、X、小红书链接及 PDF/Office 文件直接读懂。

看图、识字与渲染出图

视觉模型与离线 OCR 协同工作，纯文本模型也能看懂群里的截图；遇到表格、流程图或时序图，自动渲染成清晰图片发回聊天。

按职责拆分模型，省钱稳跑

对话、视觉、意图判断、画图各自绑定最合适的模型与供应商，保存前实测连通性，主人还能直接在聊天里切换模型。

每一步决策都有账可查

机器人为什么回、为什么没回、用了哪些工具、近 24 小时花了多少 token，事件中心一目了然，彻底告别黑盒排查。

1执行安装命令

首次生成的管理员账号和密码只在终端显示一次，请当场保存；忘记密码可随时运行 diana passwd 重置。

2打开控制台

访问 127.0.0.1:18080，用终端里显示的管理员账号登录。

3接入通道与模型

在 WebUI 里配置模型并启用任意通道，也可直接用内置机器人在控制台里开始体验。

4后续升级

控制台可直接升级，也可以重复执行安装命令；失败自动恢复。

通道支持

OneBot v11

对接 SnowLuma（推荐）等 OneBot 实现，支持群聊与私聊，群级策略精细控制回复行为。

Telegram

官方 Bot API 长轮询，出站连接，不需要公网地址。

QQ 官方机器人

QQ 开放平台 WebSocket 网关，出站长连接，不需要公网地址。

微信

腾讯 iLink Bot 扫码登录，长轮询出站，只支持私聊。

iMessage

通过 Mac 上的 BlueBubbles Server 收发，webhook 回调，可选轮询兜底。

内置机器人

无需任何平台凭据，装完即可在控制台「聊天」页直接私聊或语音通话，零门槛体验全部能力。

前四个外部平台均由本机主动出站连接，家庭或内网部署可以直接用； iMessage 只需 Mac 能访问到 Diana 即可，同样不要求公网。
