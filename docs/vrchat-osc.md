# VRChat 联动（OSC）

「VRChat 联动（OSC）」插件让机器人在 VRChat 里有一个身体：往头顶聊天框发字、按情绪切换 Avatar 表情、短时操控移动和转向，并把 VRChat 发回来的 Avatar 状态交给群聊里的 Agent 查询。它是内置插件，**默认关闭**。

它只做 OSC 这一层。Avatar 模型、Udon 房间、虚拟麦克风推流不在插件里，需要另外准备。

## 在 VRChat 里打开 OSC

1. 进入 VRChat，打开圆形菜单（Action Menu）→ Options → OSC → Enabled。
2. 同一台电脑上运行 Diana 和 VRChat 时不用改端口：VRChat 在 `9000` 收、往 `9001` 发。
3. 换过 Avatar 参数之后，在同一菜单里点 Reset Config 让 VRChat 重新生成 OSC 配置，否则新加的参数收不到。
4. VRChat 在另一台机器上时，启动参数加 `--osc=9000:<Diana 所在机器的地址>:9001`，插件里的「VRChat 地址」填 VRChat 那台机器的局域网地址，「监听地址」改成 `0.0.0.0`。

## 在 Diana 里启用

插件页找到「VRChat 联动（OSC）」，给需要的机器人打开开关。OSC 桥是整个程序共用的：任意一台机器人开着它就运行，全部关掉才停；地址、端口、映射表这几项按全局设置生效，按群覆盖不影响桥本身。设置页下方的「实时状态」会显示是否在收包、当前 Avatar、映射表里哪几行没生效。

| 设置 | 默认 | 说明 |
| --- | --- | --- |
| VRChat 地址 / 发送端口 | `127.0.0.1` / `9000` | VRChat 接收 OSC 的地址 |
| 监听 VRChat 状态 / 监听地址 / 监听端口 | 开 / `127.0.0.1` / `9001` | 端口被别的 OSC 工具占用时监听失败，发送照常可用 |
| 聊天框分段间隔 | 3 秒（最短 1.5 秒） | 长文按 144 字、9 行一段依次显示，最多排 12 段 |
| 聊天框提示音 | 关 | 每条消息只在第一段响 |
| 回复同步到聊天框 | 关 | 群里的回复同步显示在聊天框；私聊回复从不同步 |
| 心情驱动表情 | 开 | 机器人开了「心情」时，每次回复后按心情套用映射表 |
| 表情映射表 | 见下 | Agent 只能用这里写了的表情 |
| 移动单次最长 | 3 秒（最长 10 秒） | 到点自动松开 |
| 群成员可以操控 | 关 | 关着时只有主人能让机器人说话、换表情、移动 |

## 表情映射表

每行一个表情，`名称 = 参数:值`，多个参数用逗号隔开，名称可用 `|` 写别名，`#` 开头是注释。值写 `true`/`false` 是 Bool，整数是 Int（0–255），带小数点是 Float（−1 到 1）。参数名必须和 Avatar 的 Expression Parameters 一致——默认模板只是示例，照着自己的 Avatar 改：

```text
平静|neutral = Expression:0, Slump:false
开心|happy = Expression:1
疑惑|confused = Expression:2
屑|smug = Expression:3
低落|sad = Expression:4
趴桌|slump = Slump:true
```

- 「平静」是复位用的表情：Agent 设表情时带了保持时长，到点就切回它。把会“粘住”的 Bool 参数（例如 `Slump`）也写进「平静」，复位时才会一起放下。
- 心情只有三档，分别对应映射表里的「开心」「低落」「平静」，没写对应条目就不动 Avatar。Agent 刚用工具指定过的表情两分钟内不会被心情覆盖。
- 写错的行会跳过并在「实时状态」里列出，其他行照常生效。

## Agent 工具

插件启用时才注册，关着时模型看不到。

- `vrchat_status`：读当前 Avatar ID、AFK/坐下/静音等状态、正在显示的表情、最近变化的自定义参数、聊天框最后一句。群里有人问「在 VRChat 干嘛」时用它。所有人可用。
- `vrchat_chatbox`：发文字（自动分段排队）、切换「正在输入」、清空聊天框。
- `vrchat_set_expression`：按映射表切表情，可带保持秒数。
- `vrchat_move`：前后左右走、左右转、跑、跳、立即停下。每次按住不超过「移动单次最长」，到点自动松开；关闭插件时会先松开所有按住的输入。

后三个默认只给主人；插件里打开「群成员可以操控」后群成员也能用。

## 已知限制

- VRChat 只在切换 Avatar 时发 `/avatar/change`，插件启动后还没切换过就不知道当前 Avatar；Avatar 名字不在 OSC 里，只有 ID。
- 速度、口型、音量这类高频内置参数不记录，状态里只保留 AFK、Seated、MuteSelf 等能说明「在干嘛」的几项和自定义参数。
- 不做 OSCQuery 发现：VRChat 默认就往 9001 发，固定端口足够；多个 OSC 工具要共用端口时请用路由工具转发。
- 不能拍房间截图回传（需要截屏能力），也不负责语音推流。
- 按住的移动靠 Diana 进程里的定时器松开；进程被强杀的瞬间若正按着，VRChat 里会一直走，重新发一次 `stop` 或在游戏里按一下对应键即可。
