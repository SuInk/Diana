# 手机控制与热闻巡检（`official.mobile-social`）

「手机控制与热闻巡检」是随 Diana 发布、默认关闭的内置插件，同时支持 **安卓/iPhone 实体真机** 与 **各类虚拟机 / 模拟器 / 容器云手机**。它解决两件事：

1. **真机 / 虚拟机 + 公开接口混合采集**：强风控、重登录态的移动社区（**X / Twitter、小红书、小黑盒**）直接控制连接的安卓/iOS 真机或虚拟机打开 App 刷信息流；结构化开放社区（**Hacker News、V2EX**）直接请求官方公开 JSON 接口，无需唤醒设备。
2. **智能双时机群聊分享**：
   - **重磅突发主动发群（`breaking`）**：遇到行业级大新闻（例如科技巨头 CEO 回归、旗舰模型/重磅硬件发布、大作官宣），检查免打扰时段、同群冷却、每日上限和群准入后，按机器人自己在该群的人设口吻自然发群，并过一遍账号安全审核；若群里刚聊过同一件事则自动 `[SKIP]`。
   - **日常候选池顺势插话（`casual`）**：有意思但没到刷屏级的帖子存入候选池。平时群友聊到相关关键词时作为可选素材带入上下文，或群冷场触发主动开口时拿来破冰，聊过一次即对该群标记已读，不会反复复读。

启用内置 Agent 且处于标准模式时，主人还可以在私聊或群里直接通过 `mobile_device` 工具查看在线真机/虚拟机、打开应用、截屏、读取控件树、点击滑动，或说一句「现在刷一圈手机看看有什么新鲜事」立即触发 `patrol_now`。普通群成员与安全模式机器人均无法调用 `mobile_device`。

## 虚拟机 / 容器云手机接入方式（推荐 7×24 小时无人值守）

不想长期插着实体手机或担心电池老化时，可以直接跑在虚拟机或安卓容器上：

### 1. Linux 服务器推荐：Redroid（Docker 容器化安卓云手机）

[Redroid (`redroid/redroid`)](https://github.com/remote-android/redroid-doc) 是跑在 Linux Docker 里的轻量级安卓容器，支持 x86_64 与 ARM64（如 ARM 云服务器或树莓派/RK3588），内存和 CPU 开销远低于传统 QEMU 虚拟机：

```sh
docker run -itd --rm --privileged \
  -v ~/redroid-data:/data \
  -p 127.0.0.1:5555:5555 \
  redroid/redroid:android14_64only-latest
```

- 首次用 `scrcpy -s 127.0.0.1:5555` 连上去装好 X、小红书、小黑盒并登录账号；
- 在 Diana 插件设置「设备连接 → 编辑 → 高级连接 → 无线 / 容器地址」填入 `127.0.0.1:5555` 即可 24 小时稳定巡检，状态栏会自动标记为 `(android · 虚拟机)`。

### 2. Android Studio AVD 模拟器 / Waydroid / MuMu 模拟器

- **Android Studio AVD（支持自动无头拉起）**：
  - 本机已建好 AVD 时，无需提前手动打开模拟器——在插件设置「设备连接 → 编辑 → 高级连接 → 自动启动模拟器名称」填入 AVD 名称（如 `Pixel_8_API_35`），开启「后台无窗口启动模拟器」（`-no-window`），Diana 巡检发现无在线设备时会自动在后台静默拉起该虚拟机。
- **MuMu / 蓝叠 / Waydroid**：
  - MuMu 12 默认暴露 ADB 端口 `127.0.0.1:16384`（或 `127.0.0.1:7555`），Waydroid 默认暴露 `192.168.240.112:5555`，填入「无线 / 容器地址」即可直连。

### 3. macOS 原生 iOS 模拟器（Xcode `xcrun simctl`）

- Mac mini 常开部署时，可直接使用 Xcode 自带的 iOS Simulator：
  - 将连接方式设为 `自动识别` 或 `macOS iOS 模拟器`；
  - 在「模拟器名称或 UDID」填入模拟器名（如 `iPhone 16`），未启动时会自动执行 `xcrun simctl boot`；
  - **免 WDA 轻量模式**：直接用 `simctl launch` / `openurl` 打开应用或网页，配合 `simctl io screenshot` 原生截屏 + 多模态视觉模型提取信息流；
  - **完整触控模式**：若需翻页滑动与控件树点击，对模拟器附挂 WebDriverAgent（填 `http://127.0.0.1:8100`）或切到 `Mobile MCP` 即可。

## 实体真机接入方式

### 1. 安卓真机（ADB USB / 无线调试）

- 安装 Android Platform Tools（确保 `adb` 在 `PATH` 中）。
- **USB 直连**：开启「开发者选项 → USB 调试」，插线授权后无需填写地址（OPPO / OnePlus ColorOS 请同时打开开发者选项最底部的「禁止权限监控」）。
- **局域网 / Tailscale 无线连接**：开启无线调试（或 `adb tcpip 5555`），在「高级连接 → 无线 / 容器地址」填入 `192.168.x.x:5555` 或 Tailscale 地址。
- **自动唤醒与自动解锁（三种方案按需选择）**：
  1. **填写锁屏密码自动解锁**：手机设有数字 PIN 或字母数字锁屏密码时，在「设备连接 → 编辑 → 锁屏密码」填写密码（脱敏加密存放，不回显明文；不支持九宫格图案）。每次巡检若发现息屏锁屏，自动执行亮屏、呼出密码键盘并输入解锁。内置**单次熔断保护**：同一密码若解锁失败一次即停止重试，绝不循环输错触发手机锁定。
  2. **插电免锁屏常亮（备用机推荐）**：开启「设备连接 → 编辑 → 插电保持常亮」（自动下发 `adb shell svc power stayon usb`，配合把手机亮度拉到最低，最稳且不碰锁屏）。
  3. **系统级无密码 / 信任设备免密**：将备用机锁屏设为「无 / 滑动」（插件会自动亮屏上滑解开），或在主力机开启系统「延伸解锁 / 信任的蓝牙设备」（连着电脑蓝牙时上滑即开）。

### 2. iPhone 真机（WebDriverAgent / Mobile MCP）

- 在备用 iPhone 上运行开源的 [Appium WebDriverAgent](https://github.com/appium/WebDriverAgent)（USB 可用 `iproxy 8100 8100` 转发，或直接填局域网 `http://<iPhone-IP>:8100`）；
- 或选择 `Mobile MCP`，由 Diana 通过 stdio 拉起开源 [`@mobilenext/mobile-mcp`](https://github.com/mobile-next/mobile-mcp) 统一驱动。

## 巡检与防打扰策略

- **设备互斥锁**：后台定时巡检与主人聊天调用 `mobile_device` 共享同一把设备互斥锁，不会同时抢屏幕；每次巡检结束后自动按 `home` 回到桌面，避免停留在视频流里持续占满算力或耗电。
- **免打扰排队**：免打扰时段（默认 `23:00–08:00`）刷到的重磅新闻留在待发队列，等免打扰结束后若仍在时效窗口内再自动发出。
- **按群精细控制**：插件默认关闭；启用后可在「目标群号」指定白名单群，也可在「群管理」里对单个群独立开关本插件、调整冷却时长或关闭重磅主动推送（仅保留日常候选池接话）。
