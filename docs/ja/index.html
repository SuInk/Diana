人のように話し、エージェントのように働く

普段使いのチャットアプリの中に、自分だけの AI を。グループではメンションなしでも空気を読んで発言・沈黙を判断し、 記憶・Web 検索・リンクやファイル解析・Skills / MCP・ローカルコーディングエージェントまで対応。 Web コンソール内蔵の単一バイナリで、すべてのデータを自分のマシンに留めます。

なぜ Diana なのか

「雑談しかできないおもちゃ」か「設定も原因調査もつらいブラックボックス」かの二択を終わらせます。

空気を読む自然な発言

メンションなしでも会話の流れを見て参加・沈黙を判断。沈黙しっぱなしにもスパムにもなりません。応答時間帯・人設・許可リスト・ツール権限をグループ別に制御できます。

内蔵エージェント＆セーフモード

ファイル・コマンド・ブラウザツールに加え Skills や MCP を動的に読み込み、ローカルの Claude Code / Codex へ作業委任も可能。セーフモードで高リスク操作を即座に遮断できます。

単一バイナリ・完全セルフホスト

Python や Node 環境の構築は不要。ワンコマンドでサービスと WebUI が起動し、設定・記憶・ログはすべてローカル SQLite に保存されます。

マルチチャネル同時稼働・パブリック IP 不要

QQ・Telegram・WeChat・iMessage と内蔵コンソールを並列稼働。ボットごとにコンテキストを厳密分離し、自宅ネットワークでもアウトバウンド接続で動作します。

長期メモリ＆編集可能なノートブック

直近会話・圧縮要約・構造化事実・長期履歴検索を階層化し、トークン消費を抑えながらルールや好みを記憶。ノートブックはいつでも確認・編集できます。

Web 検索・リンク＆ファイル解析

既定のサンドボックスブラウザで並列検索（Exa / Tavily のグローバル設定にも対応）。Bilibili・YouTube・X・Xiaohongshu のリンクや PDF / Office 文書も直接理解します。

画像理解・OCR・図表レンダリング

ビジョンモデルとオフライン OCR によりテキスト専用モデルでもスクショやスタンプを把握。表・フローチャート・シーケンス図はきれいな画像にして返信します。

役割別モデルルーティング

会話・視覚・意図判定・画像生成ごとに最適なプロバイダとモデルを割当。保存前に実リクエストで疎通検証し、チャットからの切り替えにも対応します。

すべての判断をイベントセンターで可視化

なぜ返信したか・なぜ見送ったか・使ったツール・消費トークン数まで記録。「なぜ無反応なのか分からない」ストレスをなくします。

クイックスタート

インストーラーが OS とアーキテクチャを自動判別し、最新安定版を取得して latest.json の SHA-256 を検証します。アップグレード前の自動バックアップと障害時ロールバック付き。

1インストールを実行

初回生成された管理者アカウントとパスワードはターミナルに一度だけ表示されます。紛失時は diana passwd で再設定できます。

2コンソールを開く

127.0.0.1:18080 にアクセスし、表示された管理者アカウントでログインします。

3モデルとチャネルを接続

WebUI でモデルと任意のプラットフォームを設定。外部連携なしですぐ試せる内蔵ボットもあります。

4今後のアップグレード

コンソールから直接更新するか、同じインストールコマンドを再実行。失敗時は自動で復元します。

対応プラットフォーム

OneBot v11

SnowLuma（推奨）などの OneBot 実装と連携。グループ・DM に対応し、グループ別の細かい応答制御が可能です。

Telegram

公式 Bot API のロングポーリング。アウトバウンド接続のみでパブリック IP 不要。

QQ 公式ボット

QQ オープンプラットフォームの WebSocket ゲートウェイ。アウトバウンド接続で動作します。

WeChat

Tencent iLink Bot の QR コードログインに対応（DM 専用・アウトバウンド接続）。

iMessage

Mac 上の BlueBubbles Server 経由で送受信。Webhook とポーリングの併用に対応します。

内蔵ボット

プラットフォームの認証情報は一切不要。コンソールのチャット画面からテキスト・音声通話ですぐ体験できます。

先頭 4 つの外部プラットフォームはアウトバウンド接続で自宅回線や LAN でもそのまま利用可能。 iMessage も Mac から Diana へ到達できればよく、パブリック IP は不要です。
