# 插件的主动工具调用

正式 Agent 回复和定时执行使用同一套工具注册表。工具按需发现和加载，不需要用户输入插件命令；Diana 可以根据当前任务选择工具。主动调用不等于绕过插件开关、平台支持、群设置或用户权限，也不表示机器人会无条件主动发消息。

## 媒体工具

| 能力 | 工具 | 行为 |
| --- | --- | --- |
| 下载社交网站视频、提取图集 | `plugin_media` 的 `resolve` | 传入网页 URL，复用链接解析插件，返回本轮 `media_id` 和解析信息，不自动发送 |
| 读取下载的视频 | `plugin_media` 的 `view_video` | 使用 `media_id`，按文件解析大小上限读取视频关键帧，画面交给模型 |
| 读取公网视频直链 | `plugin_media` 的 `view_video` | 使用 HTTP(S) `url`，不接受模型提供的本地文件路径；下载层限制内网访问 |
| 发送解析结果 | `plugin_media` 的 `send` | 使用本轮 `media_id`，沿用当前平台的直发/合并转发方式；同一 ID 成功发送后不重复发送 |
| 读取当前、引用和历史视频 | `history_media` | 按消息 ID 取画面，不必重新查找视频地址 |
| 获取、搜索和发送表情包 | `sticker` 的 `search` / `send` | 沿用表情库候选、发送频率及数量限制 |
| 查看、发送网络图片 | `remote_image` | 查看真实图片后发送，不把网页标题当成图片内容 |

`plugin_media` 和 `sticker` 在按需工具目录中保留完整说明，方便模型主动发现。链接解析和文件解析都关闭时，不注册 `plugin_media`；执行时仍检查对应插件的当前开关。解析、发送要求链接解析插件启用；读取视频要求文件解析插件启用，使用解析结果读取时还要求链接解析插件启用。

视频读取依赖部署环境的 ffmpeg，沿用既有关键帧采样逻辑；结果不是逐帧全文，也不包含音轨转写。社交网站下载沿用链接解析插件已有的平台、凭据、群等级、体积、时长和清晰度限制。关闭“下载并发送媒体”后，主动解析不会强制开启下载。无法解析或读取时返回实际失败，不假称已经观看或发送。

## 其他插件

已有点歌、股票、图片溯源、AI 图片检测、文件交付、订阅及 VRChat 等专用工具继续使用原有接口和权限。第三方插件通过 `AgentTools` 或技能包提供可调用能力；只有消息处理函数或后台观察器的插件，不会被任意包装成可调用函数，以免绕过其触发条件或管理权限。
