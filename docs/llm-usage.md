# 聊天查询 Token 用量

机器人主人可以直接问「最近 24 小时用了多少 Token？」或「近一天的输入、输出和缓存命中是多少？」。模型通过只读工具 `diana.llm_usage` 查询实际日志后回答。普通用户和群管理员不能使用，平台群主也不等于机器人主人；工具注册与执行均检查权限。

统计范围是当前 Diana 实例全部机器人、全部模型的合计，窗口是查询时刻往前 24 小时，不是自然日。返回窗口起止时间、记录调用数、输入 Token、输出 Token、总 Token 和缓存命中的输入 Token。缓存命中已经包含在输入量内，不会额外计入总量。

路由、子任务等已记账用途也会计入。兼容历史日志动作名称；历史数据无需迁移。日志已清理、调用未提供用量或尚未完成时，不能得到完整消耗，因此该统计不代表供应商账户账单、费用或剩余额度。日志不可用时返回错误，不把查询失败报告成零用量。
