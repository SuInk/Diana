# 聊天查询 Token 用量

机器人主人可以直接问「最近 24 小时用了多少 Token？」或「近一天的输入、输出和缓存命中是多少？」。模型通过只读工具 `llm_usage` 查询实际日志后回答。普通用户和群管理员不能使用，平台群主也不等于机器人主人；工具注册与执行均检查权限。

统计范围是当前 Diana 实例全部机器人、全部模型的合计，窗口是查询时刻往前 24 小时，不是自然日。返回窗口起止时间、记录调用数、输入 Token、输出 Token、总 Token 和缓存命中的输入 Token。缓存命中已经包含在输入量内，不会额外计入总量。

每一次模型调用都会计入：主回复、路由判断、记忆抽取与归纳、图片与表情包描述、OCR、子任务、生图与改图、embedding 向量化、换模型前的可用性探测，以及控制台里的提供商测试和 AI 生成人设。没有挂在某条消息名下的后台调用（建索引、定时任务）也算在合计里。上游没返回用量的调用（按张计费的生图中转常见）照样计一次调用并标记为未报用量，这部分 token 无法计入，所以有这类调用时合计偏少。兼容历史日志动作名称；历史数据无需迁移。日志已清理、调用未提供用量或尚未完成时，不能得到完整消耗，因此该统计不代表供应商账户账单、费用或剩余额度。日志不可用时返回错误，不把查询失败报告成零用量。
