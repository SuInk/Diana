# X / Twitter 用户主页解析

链接解析区分单条推文和用户主页。`x.com/<用户名>`、`twitter.com/<用户名>` 以及对应的 `media`、`with_replies`、`highlights`、`articles` 主页入口展示账号资料：昵称、用户名、简介，以及接口实际返回的粉丝、关注和帖子数。受保护账号仅显示可见资料，缺失统计不会伪装成零。

主页资料通过 [FxEmbed 的用户资料接口](https://docs.fxembed.com/api/twitter/operations/2profilehandle/) 获取，不需要新增 API Key。主页入口不交给 yt-dlp，不会尝试下载整个账号的推文或媒体；单条 `/status/<id>` 推文继续沿用原有正文、图片、视频和线程解析。

此前主页没有推文 ID，元数据解析失败后误入视频下载器，产生 `Unsupported URL`，后续通用提示又归因为代理或媒体大小限制。现在主页失败时明确报告账号不可用、访问受限、限流或资料接口失败，失败结果不作为成功媒体缓存。

QQ 和 Telegram 使用同一份资料内容，并沿用各平台的现有发送方式。启用平台、群级访问限制和分享去重继续生效。关闭媒体下载仍可显示主页资料；关闭标题抓取且关闭媒体下载时保留原链接展示行为。
