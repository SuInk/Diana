# 图片发送与重试

保留现有 HTTP 分享链接发送方式。发送前为 Diana 登记的本地媒体建立使用引用，每次重试前将同一个链接续期到至少十分钟以后，来源和发送去重身份不变。

发送期间，定时清理只标记待清理，不删除正在使用的文件。发送成功、最终失败或取消后释放引用，最后一个引用释放时执行待清理操作。图片、视频、音频和文件的本地分享链接适用；外部链接不被改写。引用仅在本进程内有效，重启后的恢复仍要求分享记录和原文件存在。

群发送退避分为普通文字与媒体两个通道。图片、音频、视频、文件及合并转发的失败等待不会占用文字通道；同一通道仍保持串行重试。等待通道锁支持请求取消，避免已经超时的消息继续卡在锁上。平台确认的退群、禁言等群级不可用状态仍按原规则处理。

启用了群联调的控制台，可向 `POST /api/assistant/group-test` 传 `one_shot: true`，进行一次最长 30 秒的真实发送，不进入群发送退避队列。仍要求控制台认证与群联调开关，默认行为不变。必须以平台返回的消息 ID 验证成功。

不将图片改成 base64。该修复不保证平台上传或网络永不失败，也不能恢复已经被清除的分享记录；历史链接失效后需用保留的原图重新分享。
