# 最新版本核验与搜索时效

`web_search` 每次都会调用配置的搜索提供商，Diana 没有缓存搜索结果。但搜索提供商的索引、正文快照和网页本身更新的时间可能不同；精确 `site:` URL 没有结果，也可能只是该 URL 尚未收录或查询约束过强，不能证明页面或版本不存在。

## 处理方式

- 搜索原样执行模型给出的查询（只规范空白和脱敏），不再自动去引号、移除 `site:` 或改写关键词。模型可根据结果改变查询或直接读取 URL；多个 `queries` 独立并行执行，每个查询按配置顺序回退引擎，共享总 deadline 和提供商调用预算。
- 搜索输出提供 `retrieved_at`（本次查询完成时间）和 `source_stage`。阶段为 `search_candidates` 或 `no_sources`；网页读取为 `page_read`、`page_partial` 或 `page_empty`。阶段只描述取得的资料，不表示官方、最新或事实成立；查询时间也不是索引更新时间。不再返回固定为 false、容易被误解为核验结论的 `freshness_verified`。
- `browser_render` 读取 `https://github.com/<owner>/<repo>/releases` 或 `/releases/latest` 时，优先请求公开 GitHub `/repos/<owner>/<repo>/releases/latest` API；读取 `/releases/tag/<tag>` 时请求对应标签 API。带分页/筛选查询参数或其他站点仍走浏览器。
- API 结果标明来源、版本、`published_at` 和查询时间。latest 摘要仅覆盖 GitHub 指定的最新正式发布，不声称包含全部历史或预发布版本；指定标签的存在也不能证明它是最新。
- API 访问不使用任何仓库凭据，遵守公网地址及重定向检查，有独立超时、响应大小和总调用预算。失败时回退 Chromium；403、404、429、网络超时均不转成“版本不存在”。两条路径都失败时保留真实错误。
- `web_search` 返回候选标题、摘要和 URL，不自动读取排名前两项。模型选择相关页面后用 `browser_render` 打开或 `find` 定位；没有结果、原文未提及、读取失败均不证明不存在。来源回溯区分候选和已读页面，不再使用 claims 账本或终稿复核。

## 事实核验与回放

用户、历史、记忆和机器人先前答复中的外部事实都是待核实主张。短问从上下文还原原问题，按其实际条件查证；不能给原说法添加限定条件来表示赞同。发布、公开提供、收费、资格和渠道分别判断。保留来源的产品名、范围限定和否定条件，不将子产品可用扩写成其他渠道开放，也不将“尚未提供”改成“正在分批提供”。本轮原文未显示的日期不从摘要、旧印象或相关阅读补出；未被问到时省略，被问到时说明未确认。

工具执行后，运行时从未截断结果提取检索阶段，并附一条独立的系统提示帮助模型决定继续读取、改变查询或结束。网页、摘要和用户原话仍保留在资料消息里，不提升为系统指令。预算不足时说明证据缺口；不通过关键词或终稿判定器阻拦答复。

`TestLiveResearchReplay` 使用实际配置的模型、人设、原生工具循环和确定性来源夹具，覆盖短问、错误肯定、错误否定、截断原文与无结果。`TestLiveOnlineResearchReplay` 使用相同配置与真实搜索/浏览器插件，隔离消息发送。两者默认跳过，需要 `DIANA_LIVE_LLM=1` 和私有的 `DIANA_TEST_LLM_CONFIG`、`DIANA_TEST_BOT_CONFIG` 文件；在线回放还需 `DIANA_LIVE_RESEARCH=1` 与 `DIANA_TEST_PLUGIN_SETTINGS`。夹具不是现实发布记录；模型评估只依据本轮实际读取的正文，结果须结合工具轨迹和答复人工复核，不能视为所有后续答复的保证。

## 2026-10-06 当前模型回放

以 miku 当前的 `gemini-3.8-flash-low`、Gemini 协议和机器人配置，在 `v0.8.147-canary.4` 基线上验证：

- 五项夹具场景均通过。原始短问、错误否定和错误肯定各用一次搜索、一次原文读取；截断场景继续读取，空结果场景只说明未确认。
- miku 本机真实搜索引擎与 Chrome 回放完成一次搜索、一次官方公告原文读取，纠正了“未对公众开放、只在内部邀请测试”的说法。资料经实际工具读取，评估只使用已读资料；同时人工核对了工具轨迹、官方正文和回复。
- 回放没有向 Telegram、QQ 或其他聊天渠道发送消息。夹具与真实联网是两种不同验证，不能互相替代。单次通过也不是以后所有答复都正确的保证。

## 2026-09-18 历史实现实测（迁移前）

以下记录使用当时 Diana 默认 Exa MCP 搜索入口，自动放宽策略已在本次迁移移除。这些历史结果不代表当前浏览器搜索实现。

| 操作 | 结果 |

| 修复后读取 Gitea Release 首页 | 约 2.4 秒，官方 API 返回 `v1.27.3`，发布时间 `2026-08-29T17:42:17Z` |
