# 发言偏好

机器人设置的人设页和群管理提供同一套 0–100 滑杆：主动参与、闲聊接话、连续跟进、介入克制、新增信息要求。

关闭、低、中、高、极高分别将前三项设为 0、25、50、75、100，后两项取反向数值。选择自定义或调整任意滑杆即可独立设置各项。群可以覆盖整组偏好，也可以跟随所属机器人的当前配置。

模型根据偏好和对话上下文，分别对五项输出 `score`（0–100 整数）和 `reason`。每一项都表示按照该偏好有多支持本次发言，高分统一表示更支持；配置值与实际评分是两回事。模型不再输出 `should_reply` 或 `confidence`，代码计算五项算术平均分，达到固定的 60 分后进入回复流程，再检查独立的冷却时间。不做随机采样，不要求每项都达到 60 分；缺项、越界或非法评分不会放行。旧格式模型响应保留兼容读取，同时出现新评分和旧布尔值时以评分为准。

数值是语义倾向，不是回复概率；即使极高也不保证每条消息都回复。主动参与为 0 表示不主动插话，明确向机器人提出的请求仍正常处理。停止请求、重复回应、平台权限和准确度审核仍然生效。发送前准确度审核的 `should_send` 与发言评分独立，未改成意愿评分。

主动闲聊冷却可设置为 0–3600 秒，0 表示关闭。切换预设时，关闭、低、中、高、极高分别设置为 0、600、300、120、30 秒；修改冷却时间也会切换为自定义。冷却按机器人和会话隔离，成功发送主动闲聊后才开始计时，仅限制下一次主动闲聊，不拦截公开提问和点名请求。模型已经允许但仍在冷却时，日志会单独说明。

旧档位和回复模式折算为语义偏好，并保留旧的显式冷却时间；已有配置未设置冷却时保持 0。旧的意图提示词、社交性回应开关、插话置信度和随机采样不再决定是否发言。原配置字段保留用于读取旧版本数据；新配置以 `participation` 对象为准，冷却字段为 `cooldown_seconds`，群中的空值表示跟随机器人。`proactive_reply_threshold` 仅保留为发送前准确度审核阈值，不再是意图门槛。

发言偏好不影响消息分条、合并转发、账号安全审核、语义去重以及 RSS 订阅通知。日志记录本次实际生效的五项数值和模型理由，不再把旧阈值显示成发言判断依据。
