# 发言偏好

机器人设置的人设页和群管理只提供低、中、高、极高四档回复欲望，不再展示五维滑杆或自定义数值输入。

低：偶尔补充有用信息，尽量不打扰。中：自然参与，适当接话，聊完收住。高：更主动接话，参与闲聊和后续讨论。极高：积极参与分享和玩梗，也更愿意继续聊。群可以选择自己的档位，也可以跟随所属机器人的当前配置。

四档各自对应一段接话规则。为兼容旧配置，仍保留历史字段，但运行时只用主动程度折算档位，不再把五维数值交给模型评分。旧自定义配置按主动程度就近折算为低（1–37）、中（38–62）、高（63–87）、极高（88–100）；原有关闭状态继续保留，明确请求仍可回应。冷却单独保留。

模型根据当前档位规则和上下文直接返回 `should_reply`（是否接话）、`category`（交流类型）、`target_message_id`、`turn_message_ids` 和简短的 `reason`。不再输出五项评分，也不计算平均分或置信度门槛，不做随机采样。模型决定保持沉默时程序不擅自放行；决定接话后再检查独立冷却。格式错误或只有旧评分、没有明确布尔决定的响应不会放行；附带旧评分不会覆盖布尔决定。

极高也不要求每条消息都回复。明确向机器人提出的请求仍正常处理，停止请求、重复回应、平台权限和准确度审核仍然生效。发送前准确度审核的 `should_send` 与接话判断独立。

主动闲聊冷却是独立配置，默认 30 秒，可设置为 0–3600 秒，显式设置 0 表示关闭。切换回复欲望档位不会修改冷却时间；修改冷却时间也不会改变欲望档位。冷却按机器人和会话隔离，成功发送主动闲聊后才开始计时，仅限制下一次主动闲聊，不拦截公开提问和点名请求。模型已经允许但仍在冷却时，日志会单独说明。

旧档位和回复模式折算为语义偏好，并保留旧的正数冷却时间；未设置冷却时使用 30 秒。旧的意图提示词、社交性回应开关、插话置信度和随机采样不再决定是否发言。原配置字段保留用于读取旧版本数据；新配置以 `participation` 对象为准，冷却字段为 `cooldown_seconds`，群中的空值表示跟随机器人。显式设置为 0 的新配置会保留该字段，保存和重新加载后仍表示关闭冷却。`proactive_reply_threshold` 仅保留为发送前准确度审核阈值，不再是意图门槛。

发言档位不影响消息分条、合并转发、账号安全审核、语义去重以及 RSS 订阅通知。日志直接记录生效档位、接话决定、原因和冷却，不再显示五维评分或平均分门槛。
