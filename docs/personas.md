# 人设预设与自定义

人设选择器包含固定的“自定义”项和人设库中的已保存条目。旧机器人配置没有 `persona_id` 时始终显示自定义，不根据相似内容自动认领预设，不改写已有提示词。

人设覆盖基础正文、表达风格、自称、句尾语气词、动作描写和时段语气。修改其中任一项后转为自定义；回复欲望、冷却和机器人标记不属于人设，调整它们不会改变人设选择。

选择预设时保留当前自定义内容到 `custom_persona`，保存机器人配置后也会保留这份快照。切回自定义恢复该内容。预设是复制到机器人配置的快照，不与库中条目实时绑定。

“添加人设”将当前正文和表达设置保存为新条目，同名时另存副本。删除只移除库中的条目，不清空已经使用的机器人正文；删除当前选择的条目后，当前内容显示为自定义。自定义项本身不可删除。
