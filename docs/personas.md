# 人设预设与自定义

人设选择器包含固定的“自定义”项和人设库中的已保存条目。旧机器人配置没有 `persona_id` 时始终显示自定义，不根据相似内容自动认领预设，没有旧表达风格配置时不改写已有提示词。

人设覆盖基础正文、自称、句尾语气词、动作描写和时段语气。修改其中任一项后转为自定义；回复欲望、冷却和机器人标记不属于人设，调整它们不会改变人设选择。

选择预设时保留当前自定义内容到 `custom_persona`，保存机器人配置后也会保留这份快照。切回自定义恢复该内容。预设是复制到机器人配置的快照，不与库中条目实时绑定。

“存为人设”将当前正文和表达设置保存为新条目，同名时另存副本。删除只移除库中的条目，不清空已经使用的机器人正文；删除当前选择的条目后，当前内容显示为自定义。自定义项本身不可删除。

表达方式直接写在人设正文中，不再提供独立的表达风格选项，也不再运行时叠加风格模板。旧 `reply_style` 在读取配置或导入人设时一次性融合进正文并清空；保存或导出后不再包含该字段。群级旧风格没有自定义正文时，会以继承的机器人正文为基础生成可编辑的群级人设。回复欲望保持独立。
