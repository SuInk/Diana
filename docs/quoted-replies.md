# 明确引用机器人的回复

已确认引用当前机器人消息、并已进入回复流程的请求，按直接追问处理，不套用主动闲聊的准确度阈值或“没必要插话就静默”的分支。事件结果使用 `replied_direct_followup`，避免已经花时间生成答案却记作 `ignored_proactive_reply_quality`。

引用身份根据原消息发送者 ID 与当前通道机器人 ID 核对，不按显示昵称、复制的引用文字或其他群的材料判断。引用其他群友不获得此待遇。是否回应仍遵守前置意图判断、明确停止请求、平台权限和语义去重；此改动不强制回复每个表情或结束语。

发送前处理与普通直接回复一致：配置启用的账号安全审核和已有图片依据核验仍然生效。此改动不意味着答案已被保证正确，也不新增自动纠错或重新搜索机制。
