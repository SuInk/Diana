# 机器人标记与群消息抑制

Telegram 默认使用消息发送者的 `is_bot` 标志识别平台 Bot。匿名管理员和频道身份不会仅因 Telegram 的代理发送者标志而被当作 Bot；普通账号运行的自动回复程序也不会自动带有 `is_bot`。QQ 及 Telegram 均可手动标记账号。

控制台的机器人设置、人设页可以维护“本机所有群”的名单，群管理可以维护本群补充名单。两份名单取并集，均归属于所选机器人，不与其他机器人共享；取消本群标记不会移除机器人范围内的标记。名单只影响群消息，不改变私聊、订阅推送或其他插件的配置。

被平台识别或手动标记的机器人消息，先由 LLM 根据当前上下文判断是否在向本机接话。未提到、无法确认或判断失败时不回复；确认在向本机接话时可以继续正常回复流程，原有准确度和防循环审核仍然有效。Telegram 的自动抑制开关仅控制平台 Bot 的自动识别，手动名单独立生效。

主人可以自然语言要求“把我引用的这个账号标记为机器人，只在这个群生效”“将账号 123 标记为机器人，对本机所有群生效”“取消账号 123 的机器人全局标记”。模型通过 `diana.bot_markers` 工具选择目标和范围，不使用关键词指令匹配，不根据聊天内容擅自给用户永久贴标签。群范围的操作需在目标群内发起；无法确认目标 ID 时应先询问。

聊天中的名单管理工具只对本机主人开放，工具执行时再次校验主人身份。群主和群管理员的自助配置权限不包含修改机器人标记；已登录完整控制台的管理者可从 WebUI 管理。机器人范围的保存只修改该机器人的名单，不切换当前激活机器人；持久化失败会报错，不在运行时应用未保存的结果。
