# 链接解析翻译

在「扩展 → 链接解析 → 设置 → 媒体与发送」开启「翻译为中文」。默认关闭，不增加模型调用；开启后使用当前机器人的聊天模型，为解析出的内容附上简体中文译文，长文生成摘要。

原文、原链接、图片和视频保留。普通消息在原文后附上译文；合并转发增加一个译文节点。模型不能修改原始媒体地址，译文中的控制标记按普通文字处理。翻译与「发送后自然点评」独立。

每条入站消息最多发起一次翻译，整体最多等待 15 秒。最多读取解析结果前 12,000 个 Unicode 字符，不追加抓取全文；超过 2,000 字的内容要求模型给出摘要。未配置模型、模型请求失败、超时、空结果或过长结果均回退原文，继续投递已有图片和视频。此开关仅处理链接解析插件实际提取的文本，交给 Agent 浏览器处理的网页不经过该步骤。
