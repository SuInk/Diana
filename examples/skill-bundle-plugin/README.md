# Skill 脚本插件示例

把本目录内容放到你自己的 GitHub 仓库根目录，修改插件 ID 和说明，再通过 Diana
插件页预览、安装该仓库。此目录不是可直接粘贴安装的仓库子路径。

在机器人设置中打开 Agent，并把 `node` 加入命令白名单。服务器须安装 Node.js；
插件不会自动安装依赖或修改白名单。这个例子不需要网络，可保持沙盒网络关闭。

主人发送「用示例脚本问候嘉然」：模型读取 `hello` Skill 和参考文档，通过运行时提供
的固定 `hello` 入口调用脚本，并转述结果。插件设置中的问候前缀会传给脚本。

停用插件后，新会话不会收到该 Skill 或工具，已有工具引用也会拒绝执行。
脚本、MCP 和凭据的完整配置见仓库的 `docs/third-party-plugins.md` 第 8 节。
