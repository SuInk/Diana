# 世界书示例

可以直接在 WebUI「机器人 → 人设 → 世界书 → 导入」里选中的文件。格式说明见
[配置文档](../../docs/configuration.html#world-book-romance)。

这个文件是手写的：纯 JSON，`id` 只用来表达文件内部的父子引用，导入时会统一
换成新 ID 并按引用重连，不会和本地已有节点撞车。

| 节点 | 注入方式 |
| --- | --- |
| `世界` | 常驻——每轮都注入，写世界的骨架 |
| `世界 / 港口` | 触发词 `港口,码头,钓鱼`——聊到才注入 |
| `世界 / 钟楼` | 触发词 `钟楼,老城区` |

导入只增不减：文件里引用不到的父节点会提到根，不会去猜本地哪个节点算它爹。

同一个导入入口也认 SillyTavern 的世界书文件（顶层 `entries`）和角色卡内嵌的
`character_book`：蓝灯 `constant` 折算成常驻，绿灯关键词折算成触发词。
